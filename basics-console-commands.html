Console Commands

Every kgxat_ console command in the toolbox, grouped by who can run it, with what each one does.

Guide / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does

  5. Tips and limits

What it does

The toolbox adds console commands that start with kgxat_. Players use them to open menus or bind keys. Admins use them for actions on the whole map, such as locking every door. Some are meant for the server console, for example to unban yourself.

Commands you run from your own console can be bound to a key with bind <key> <command>. Settings > Keybinds covers the common keys without the console.

Where to find it

Open your game's developer console and type the command. Server owners can also type server commands in the server console or over rcon.

Who can run a command is listed in each table. "Admins" means toolbox admins; see the Getting Started guide.

Debugging

These run on your own computer and print to the console or open a window.

Command What it does
kgxat_debug_console Opens the debug console window (tabs Calls, Net, Tool settings, Report)
kgxat_debug_report Prints the debug report
kgxat_perf_client [seconds] (old name kgxat_hookprofile) Times every toolbox hook on your game for 2-60 seconds (default 10), then prints the costliest
kgxat_owner add <SteamID or part of a name> / remove <SteamID> / list / clear Server console (or rcon) only: sets the server owners, a level above superadmin (v3.6.12; Settings > Permission Report)
kgxat_spawn_whitelist 0/1 Server: 1 = players spawn only what is on the spawn whitelist (Settings > Spawn Whitelist)
kgxat_perf [seconds] Server console or superadmins: times every toolbox hook and net message on the server for 2-60 seconds (default 10), then prints the costliest
kgxat_wipedata map / allmaps / everything confirm [logs] Server console (or rcon) only: backs everything up, deletes the toolbox's saved data (this map's world data, every map's, or everything; owners, ranks, bans and warnings are kept, logs only with logs) and restarts the map so it loads blank (v3.6.13.1)
kgxat_moneylog <name / SteamID> [YYYY-MM-DD] Admins (Money Log access) or the server console: the last 60 money changes of that player (or everyone) that day, and the top gains
kgxat_fast_draw 0/1 1 (default) = spray paint and rain drawn in batches; 0 = one by one
kgxat_hud_debug Prints why the toolbox HUD draws or not
kgxat_preview_scan Prints what the hover preview can show (spawn menu lists and icons)

How to use it

Bind third person to a key from the console
  1. Open the console.
  2. Type bind h kgxat_thirdperson and press Enter.
  3. Press H in game to switch third person on and off.
Unban yourself after a mistake
  1. Open the server console (or rcon).
  2. Type kgxat_unban STEAM_0:1:12345678 with your own SteamID.
  3. The toolbox ban and the engine ban for that SteamID are both cleared.
Start this map from blank
  1. Open the server console (or rcon).
  2. Type kgxat_wipedata map confirm.
  3. A backup is saved, this map's warps, zones, stores, permanent props, doors and the rest are deleted, and the map restarts in 10 seconds. Settings > Backup / Restore can bring it all back.
Lock every map door
  1. As an admin, open the console.
  2. Type kgxat_mapdoors lock.
  3. Doors of bought properties are left alone. Type kgxat_mapdoors default to undo it.

Tips and limits

  • kgxat_mapdoors, kgxat_unbreakable_doors and kgxat_physblock_map save for the current map only.
  • kgxat_mapdoors with no word prints the usage and the current mode.
  • kgxat_unblock from a player who is not a superadmin does nothing.
  • With kgxat_physblock_map 4 from the server console, list the ranks after the mode, separated by spaces.
  • kgxat_unblockme does not take an admin out of jail; only superadmins leave jail with it.
  • Server settings (kgxat_superadmin_only and the others) are convars, not commands: see the Getting Started guide and Settings > Server Settings.
