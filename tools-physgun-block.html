Physgun Block

Block the physics gun on anything, map props too: for everyone, players only, admins only or certain ranks. Saved for the map.

Tool / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Physgun Block stops the physics gun on one entity. It works on props, map props, doors, vehicles, NPCs and anything else except players. You choose who is blocked: everyone, players only, toolbox admins only, or certain ranks.

A blocked entity shows no beam and cannot be picked up. If another addon allows the pickup first, the entity is dropped at once. Physics gun reload does not unfreeze it either.

Blocks on map entities and permanent entities are saved for the map. Panel buttons block or unblock every physics prop of the map in one go.

Where to find it

Q menu > KGX's Admin Toolbox > Properties > Physgun Block.

Admins only by default. A superadmin can give it to all players or to one rank in Settings > Player Access. That tick also lets them block or unblock every physics prop of the map at once.

Given to a player (v3.6.11.3): Their own props, against other players.

Controls

Key What it does
Left Block the physics gun on the aimed entity, for the people chosen in Blocked for.
Right Remove the block.
Reload Copy the aimed entity's block setting into the panel.

While the tool is out, the text under your crosshair says "Physics gun: not blocked" or "Physics gun blocked for ...". Blocked things within about 2000 units are outlined orange.

Options

Option What it does Default
Blocked for Who cannot pick it up. See the table below. Everyone (admins and superadmins too)
Ranks (for "Certain ranks"), comma separated Rank names for the "Certain ranks" choice. empty
Add a rank Lists the server's ranks. Picking one adds it to the ranks box.
Block every physics prop of the map (setting above) Blocks every map physics prop with the current Blocked for setting.
Unblock every physics prop of the map Removes the block from every map physics prop.
Reset to defaults Puts Blocked for and the ranks box back to their defaults.

Who is blocked

Choice Effect
Everyone (admins and superadmins too) Nobody can pick it up. Use right-click with this tool to undo it.
Players only (toolbox admins may still move it) Players cannot; anyone the toolbox treats as an admin still can.
Toolbox admins only (players may still move it) Admins cannot; players still can.
Certain ranks (listed below) Only players whose rank is in the ranks box.

Ranks match by name only. A rank that inherits from a listed rank is not blocked.

How to use it

Keep players from moving a prop
  1. Set Blocked for to Players only (toolbox admins may still move it).
  2. Aim at the prop and left-click.
  3. Admins can still move it; players get no beam.
Block a prop for VIPs only
  1. Set Blocked for to Certain ranks (listed below).
  2. Pick the rank in Add a rank, or type it in the ranks box.
  3. Left-click the prop. With an empty ranks box the tool refuses and asks for a rank.
Block every map prop
  1. Choose the Blocked for setting you want.
  2. Click Block every physics prop of the map (setting above). You get "N map props blocked for ... (saved for this map)."
  3. To free them, click Unblock every physics prop of the map.

Settings and commands

Command What it does
kgxat_physblock_map <0-4> [ranks] Blocks every map physics prop: 0 = off, 1 = everyone, 2 = players, 3 = admins, 4 = ranks. Saved for this map. From the server console, list the ranks after the number.

Tips and limits

  • Map entities are saved by their map ID in data/kgx_admin_toolbox/physblock_<map>.json. They stay blocked after cleanups and restarts.
  • Permanent entities (World > Permanent Entities) keep the block in their permanent entry. Other spawned things stay blocked until they are removed; the tool tells you so.
  • "Every physics prop of the map" means prop_physics variants and func_physbox placed by the map.
  • A held entity is dropped the moment you block it.
