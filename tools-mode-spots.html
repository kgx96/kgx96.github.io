Mode Spots

Team spawns, lobby and spectator spots for Game Modes matches, per mode and map.

Tool / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Mode Spots sets where Game Modes matches put players on this map. You place team spawns, the lobby, the spot the dead watch from, and objectives such as capture points, flags, bomb sites and escort paths.

Each spot is for one mode or for every mode. A match uses the spots of its own mode, else the ones for every mode, else the map's own spawns. Spawns can be for one team or for any team.

Spots are saved per map. Markers show only while you hold the tool.

Where to find it

Q menu > KGX's Admin Toolbox > World > Mode Spots.

Admins can use the tool, and players who are given Mode Spots in Settings > Player Access. Modes themselves are made in Utilities > Game Modes.

Admins only (v3.6.11.3): this tool sets up the server, so it cannot be given to players; it is greyed out in Settings > Player Access.

Controls

Key What it does
Left click Add a spot here (facing where you look)
Right click Remove the spot nearest to where you aim
Reload Remove every spot of the kind / team / mode picked in the menu (twice)

Right click removes the nearest spot within 96 units. Reload asks you to reload again within 3 seconds before it removes anything.

The panel

Option What it does Default
For the mode Every mode, or one mode from Utilities > Game Modes. Every mode
Kind What the spot is. See "The spot kinds" below. Spawn
Team (spawns and flags; 0 = any team) Team number, 0-8. Only used by spawns and flags. 1
Radius (points, zones, sites, escort, checkpoints) Size of an objective or a race checkpoint, 32-2000. 150

The spot kinds

Kind Use
Spawn Where players of a team (or any team with 0) spawn in a match.
Lobby (waiting for the match) Where players wait before the match.
Hub (where everyone is between matches; every mode) v3.6.15. With at least one hub spot on the map (and not on RP servers) the map has a hub: players outside a match spawn on a hub spot with only their Hands (toolbox admins keep their gear), cannot get hurt, and everyone respawns here after each match with what they had in the hub (the match gear is gone, the old position is not used). Admin Events rounds and teams are not affected. Settings: Utilities > Game Modes > Hub. Always for every mode.
Enemy spawn (Waves: where the NPCs come from) v3.6.17. Where the enemies of a Waves (PVE) match such as Survival appear; a Waves mode opens no lobby without one. Each enemy uses a random one, so spread a few around the map, away from the players' spawns. Shown in red while you hold the tool.
Spectators (the dead, when they may not watch players) Where the dead watch from.
Objective: capture point (teams take and hold it) Teams take it and score while they hold it.
Objective: hold zone (score while alone on it) Whoever is alone on it scores.
Objective: flag (a team's base; pick the team) A team's flag. Needs team 1-8.
Objective: bomb site (the attackers plant here) Attackers plant the bomb here by holding E.
Objective: escort path (add the nodes in order) The cart's path, one node per click, in order.
Race checkpoint (add them in order; the last one is the finish) A checkpoint of a race (v3.6.10). They count in the order you place them; the radius is how close a racer must get. While the tool is out each one shows its number.

How to use it

Set team spawns for Team Deathmatch
  1. Set For the mode to Team Deathmatch, or Every mode to share the spots.
  2. Set Kind to Spawn and Team to 1.
  3. Aim at the floor where a player should appear and left-click. The spot faces the way you look. Add several.
  4. Set Team to 2 and do the same on the other side.
Add a lobby and a spectator spot
  1. Set Kind to Lobby (waiting for the match) and left-click where players should wait.
  2. Set Kind to Spectators and left-click where the dead should watch from.
Build an escort path
  1. Pick the mode and set Kind to Objective: escort path.
  2. Set the Radius.
  3. Left-click each node from start to end. The order you place them is the path.
Build a race track
  1. Pick the mode (Race, or every mode) and set Kind to Race checkpoint. Set the Radius to the width of the track.
  2. Left-click each checkpoint in the order racers must pass them. The last one is the finish; with more than one lap, racers go from the last back to the first.
  3. Place the racers' start with Spawn spots before the first checkpoint.
  4. Start the Race mode. Without at least 2 checkpoints the lobby does not open and says what to place.
Clear spots and start over
  1. Pick the same mode, kind and team in the panel.
  2. Press reload, then reload again within 3 seconds.

Tips and limits

  • At most 512 spots per map. They are saved in mode_spots_<map>.json.
  • Place a few hub spots spread out: players spawn on a free one. Remove them all to turn the hub off.
  • Markers: boxes in team colors (green = hub, blue = lobby, grey = spectators) with an arrow for the facing. Objectives also show their radius.
  • Labels above the markers show the kind and the mode within 1500 units.
  • Objectives work in any team mode that has them on the map. The built-in Team Objectives mode is made for them.
  • With bomb sites or an escort, the defenders win when the time runs out.
  • Objective settings are per mode: Utilities > Game Modes > edit a mode.
  • Reload with Kind set to Spawn or Flag removes only that team's spots. Other kinds ignore the team.
