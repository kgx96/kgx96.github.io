Chat Commands

Every chat command the toolbox adds, for players and for admins, with what each does and who can use it.

Guide / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

The toolbox answers a set of chat commands. Players use them to open menus, handle money, vote and join matches. Admins get quick moderation commands such as !bring, !goto and !kick.

Almost every command works with either ! or / in front, for example !rules or /rules. The exceptions are @ (admin chat) and !licenses, which only works with !.

A command the server handles is not posted to chat. !licenses and !voice are handled by your own game instead. Many commands only work when the feature behind them is on, for example the economy, jobs or Game Modes.

Where to find it

Type the commands in the normal chat box. Admins can type !help (or !commands) for the list of admin commands in chat.

The in-game README also lists them: Q menu > KGX's Admin Toolbox > Settings > Patch Notes & README > README (everything) > Player chat commands.

How to use it

Target a player with an admin command
  1. Type part of the player's name, for example !bring joh.
  2. If more than one player matches, type more of the name.
  3. For a name with spaces, use quotes: !kick "John Doe" spamming.
  4. Use ^ for yourself and @ for the player you aim at, for example !god ^ or !freeze @.
Report a player
  1. Type !report followed by what happened and who, for example !report Mike is prop-killing at spawn.
  2. Wait 60 seconds before sending another report.
  3. Admins read it in Q menu > KGX's Admin Toolbox > Utilities > Reports.
Start a map vote with rock the vote
  1. Type !rtv once the map has run for kgxat_rtv_wait minutes (5 by default).
  2. When enough players have typed it, a map vote starts.
  3. Press the number key of your pick, or type !vote <number>.

Tips and limits

  • Admin chat commands use the same permissions, rank immunity and logging as the Player Manager.
  • A player who may not use the Player Manager gets no answer from the admin commands, so another addon can handle them.
  • Gagged players can still use !rules, !report, !warp, !warps, !vote <number>, !money, !wallet, !balance, !bank, !atm, !backpack, !bp, !dropmoney, !dropcash and !give. Their @ messages are blocked.
  • !build, !pvp and !mode do not work during a Game Modes match; !leave first.
  • !leave is only taken by the toolbox when you are in a match, so other addons can use it otherwise.
  • !sitout while in a match leaves the match.
  • Most player commands also have a console command, for example kgxat_backpack_open or kgxat_jobs. See the Console Commands guide.
