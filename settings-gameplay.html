Gameplay

Pick the server mode (Sandbox, Build / PvP or RP) and set the RP rules, movement, poop by a timer, citizens, Build/PvP, anti prop-kill and death screen.

What it does

Gameplay is where you choose how the whole server plays. The Server mode box switches between Sandbox, Build / PvP and RP. The rest of the page sets the rules that go with each mode.

It also holds movement speeds, players pooping by themselves on a timer (and what E on a poop does), the citizen rank and spawn weapons, anti prop-kill, the death screen and kill cam, and the on/off switches for item spawners and vehicle pads.

While DarkRP runs, RP mode uses DarkRP's own jobs, doors and rules instead of the toolbox's.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Gameplay.

Anyone can open the page, but only superadmins can change the settings. The controls are greyed out for everyone else. The last checkbox, Show my Build/PvP mode, is a personal setting every player can change.

Players switch between Build and PvP with the chat commands !build, !pvp and !mode. Anyone can see the current server mode with !servermode.

The panel

Checkboxes and the three drop-down boxes apply as soon as you change them. Sliders only apply when you click Apply the numbers above near the bottom of the page.

How to use it

Run an RP server
  1. Open Settings > Gameplay as a superadmin.
  2. Set Server mode to RP (jobs, property, RP rules). Every player is told the new mode.
  3. Tick or untick Only admins can noclip and Players can only spawn props to taste.
  4. Set Citizens to In RP mode, then type the weapons citizens get in Citizens spawn with and click Apply.
  5. Set up jobs in Settings > Jobs and property in World > Property.
Run a Build / PvP server
  1. Set Server mode to Build / PvP. Everyone is put back into the default mode.
  2. Tick New players start in Build mode if builders should be the default.
  3. Move Seconds between switches and Seconds after a fight before Build mode is allowed, then click Apply the numbers above.
  4. Tell players to type !build or !pvp. Builders get a blue BUILD tag above their head.
Put a player in Build or PvP mode yourself
  1. Open the player's menu in the Player Manager.
  2. Click Put in Build mode or Put in PvP mode. No cooldown applies.

Tips and limits

  • Build mode players cannot hurt players and cannot be hurt by players, their props or their vehicles. NPCs and the world still hurt them.
  • Players cannot switch to Build mode while jailed or during a Game Modes match.
  • Leaving Build mode ends a player's noclip (admins keep theirs).
  • The citizen rank and weapons text boxes only accept letters, numbers, _, - (and commas, spaces and dots for weapons).
  • Admins and other ranks are not changed by the Citizens setting. Outside RP mode, a Settings > Player Loadouts entry for the citizen rank wins over the citizen weapons.
  • During a kill cam, E changes the view (killer, victim, overview). Respawning ends it. Admins can replay any of the last 60 kills from Utilities > Damage Log (right-click a kill).
  • Typed slider values stay unsent until you click Apply the numbers above.
