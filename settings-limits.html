Limits

Set how many toolbox things each player may have at once, and cap how strong a limited player's tools can be.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Limits sets how many of each toolbox thing a player may have at once: doors, buttons, keypads, teleporters, zones, stores and more. It also sets per-use caps, such as props per prefab paste. A limit of 0 means not allowed.

The second half sets value caps: the most a limited player's tool may do. A higher tool setting is lowered to the cap.

Toolbox admins are not limited unless Limits also apply to admins is ticked. Superadmins are never limited. Limits matter for players given tools through Player Access or a license.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Limits.

Everyone can read the limits. Only superadmins can change them; for everyone else the controls are greyed out, with the line "Only superadmins can change limits."

How to use it

Lower a limit
  1. Open Q menu > KGX's Admin Toolbox > Settings > Limits as a superadmin.
  2. Move the slider, for example Doors (Door Maker) to 2.
  3. Press Apply limits and caps.
  4. A non-admin with Door Maker access can now make 2 doors; the third is refused.
Forbid one kind of thing
  1. Set its slider to 0.
  2. Press Apply limits and caps. Players get "<name>: not allowed for you on this server."
Limit admins too
  1. Tick Limits also apply to admins.
  2. Toolbox admins now follow the same limits and caps. Superadmins still do not.

Settings and commands

Tips and limits

  • Counts are what a player has right now. Removing something frees its slot.
  • Players see a notice such as "Doors 3 / 10" after placing one.
  • At the limit, players see "Limit reached: <name> <count> / <limit>."
  • Buttons and keypads saved with the server do not count toward a player's limit.
  • The tool cooldown for limited players is in Server Settings.
  • The reset window in Server Settings ("Server settings, limits and caps") also resets this page.
