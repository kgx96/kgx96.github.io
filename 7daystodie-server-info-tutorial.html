7 DAYS TO DIE MOD

KGX Server Info.How to use it.

KGX Server Info shows your welcome text and server rules to players as they join. These guides cover the player side, writing your texts and choosing how strict the rules are.

Tutorial 01

As a player: the welcome window and the rules

What players see when they join.

  1. On your first join the Server Info window opens by itself with the server's welcome text.
  2. Open the Rules tab, read them and press Accept. On some servers you must accept before you can play.
  3. The Server tab shows the world, day, blood moon, loot and XP settings, the KGX mods and the admins' links. Copy links copies the web addresses.
  4. Press Home any time to open the window again (personal setting infoHotkey), or type kgx info open.

Tutorial 02

Admin: write the welcome text and rules

Fill in every text in game.

  1. Press Home and open the Edit tab (admins only, permission info.admin).
  2. Pick a section: Welcome, Rules, Message of the day, Announcements or Server lines.
  3. Type one line per box. Lines > and < Lines show the next or previous 10 lines.
  4. Use {server} and {player} in the welcome text; they are filled in for each player.
  5. Press Save. Undo changes throws away what you did not save.

Tip: Everything is stored in serverinfo.txt in the world's KGX folder. You can edit it by hand and run kgx info reload.

Tutorial 03

Admin: choose how strict the rules are

Decide what happens to players who do not accept.

  1. Open the KGX Settings window (F2) and pick KGX Server Info.
  2. Set rulesMode: Show until accepted (the rules open on every join until accepted), Freeze until accepted (players cannot move, fight or be hurt until they accept), Kick on decline (declining disconnects; so does no answer within acceptMinutes) or Information only.
  3. reacceptOnChange: everyone accepts again after you change the rules (default on).
  4. adminsAccept: admins must accept too (default off). Admins and the host are never kicked.
  5. showWelcome: show the welcome window on the first join, every join or never.

Tip: Test it on yourself: turn on adminsAccept and run kgx info reset to accept again.

Tutorial 04

Admin: message of the day and announcements

Tell every player what is going on.

  1. In the Edit tab, the Message of the day shows as a toast a few seconds after every join (empty = none).
  2. In Announcements, start each line with the minutes, then the text: 30 Join our Discord shows every 30 minutes (5 to 1440). Up to 10 lines.
  3. kgx info announce Restart in 10 minutes shows a message to everyone right now.
  4. The server setting announcements turns all timed announcements off.

Tutorial 05

Admin: commands

Check and reset who accepted.

  1. kgx info open [tab] and kgx info rules for every player.
  2. Admin: kgx info status shows the rules mode and whether each online player accepted; kgx info reload reads serverinfo.txt again; kgx info reset [player|all] makes players accept the rules again.
