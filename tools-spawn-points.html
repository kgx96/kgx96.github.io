Spawn Points

Custom player spawn locations, saved for this map.

Tool / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does
  2. Where to find it
  3. Controls

What it does

Spawn Points places custom spawn locations for the current map. When custom spawns are on and the list is not empty, players respawn at a random spawn point from it.

Each spawn point remembers the direction you were looking when you placed it. Players face that way when they spawn. An arrow on the marker shows the direction.

Jailed players still respawn in jail. A job with its own spawn (Jobs editor) sends its members there first, whether custom spawns are on or not.

Where to find it

Q menu > KGX's Admin Toolbox > World > Spawn Points.

Toolbox admins can use it. Superadmins can also give it to players in Settings > Player Access. Only superadmins can turn custom spawns on or off with reload. Players remove only the spawn points they placed.

Admins only (v3.6.11.3): this tool sets up the server, so it cannot be given to players; it is greyed out in Settings > Player Access.

Controls

Key What it does
Left-click Add a spawn point where you aim (facing your view direction)
Right-click Remove the spawn point nearest to where you aim
Reload Turn custom spawns on/off (superadmin)

While you hold the tool, the screen shows the number of spawn points and Custom spawns: ON or OFF. Markers are only visible while this tool is out.

Options

Option What it does Default
Name for new spawn points (optional) Name given to spawn points you place (up to 32 characters). Empty
All spawn points on this map

A list with #, Name and Distance columns. Unnamed spawn points show as Spawn 1, Spawn 2 and so on. Double-click a row to go there.

Right-click a row for Go there, Rename..., Copy position and Remove.

Button What it does
Rename selected spawn point... Names the selected spawn point. Empty removes the name.
Add a spawn point where I stand Adds a spawn point at your feet, facing where you look.
Refresh Reloads the list.
Remove all spawn points on this map... Removes every spawn point after a confirmation. This cannot be undone.

How to use it

Set up spawns for a map
  1. Stand where players should spawn and look the way they should face.
  2. Aim at the floor and left-click. Repeat for every spawn spot.
  3. Check the screen text. If it says Custom spawns: OFF, a superadmin presses reload to turn them on.
  4. Respawn to test: you appear at one of the spawn points.
Add a spawn point exactly where you stand
  1. Stand on the spot and face the right way.
  2. Click Add a spawn point where I stand.
Remove a spawn point
  1. Aim at the floor next to its marker (within 128 units) and right-click.
  2. Or right-click it in the list and choose Remove.

Settings and commands

Setting What it does Default Range
kgxat_custom_spawns 1 = players respawn at the spawn points placed with World > Spawn Points (if any exist). Shown in Settings > Server Settings as Use custom spawn points (World > Spawn Points). 1 0 to 1
kgxat_limit_spawns Most spawn points a non-admin player may place (Settings > Limits). 0 = not allowed. 3 0 to 64

Tips and limits

  • Saved per map in data/kgx_admin_toolbox/spawns_<map>.json.
  • A map holds at most 64 spawn points.
  • With no spawn points on the map, players use the map's normal spawns.
  • Admin Vision can also show every spawn point (Utilities > Admin Vision).
