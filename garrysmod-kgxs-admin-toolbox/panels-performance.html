Performance

Live server load (FPS, entities, moving props, memory) and the players who own the most props, with freeze and remove actions.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

Performance shows live server load. It refreshes every 2 seconds while the panel is open.

It lists the 15 players who own the most props, with how many of those props are moving. Moving props cost the most, so freezing them helps right away. You can freeze or remove everything one player owns, or freeze every prop on the map in an emergency.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Performance.

Toolbox admins can use it. Players can get it through Settings > Player Access with the Entities (status, counts, bulk remove) tick. For players, the emergency freeze button needs the Server Tools (incl. time scale / gravity) tick instead.

How to use it

Find what is slowing the server
  1. Open Utilities > Performance.
  2. Compare Server FPS with the tickrate. FPS well below the tickrate means the server is struggling.
  3. Check the moving count next to Props. Moving props cost the most.
  4. Look at the Moving column to see whose props are moving.
Stop one player's props
  1. Right-click the player's row.
  2. Pick Freeze everything (name) owns to stop the load without deleting anything.
  3. If needed, pick Remove everything (name) owns... and confirm with Remove.
Find what the toolbox costs
  1. Press Time the toolbox on the server (10 s) (or type kgxat_perf 10 in the server console).
  2. Play normally for 10 seconds.
  3. Open the console (~). The first line gives the time all toolbox hooks took per tick and the share of a tick that is. The table lists the costliest hooks and net messages: milliseconds per tick, how many calls, and the slowest single call.
  4. Do the same on your own game with Time the toolbox on my game (10 s): there the numbers are per frame.
Stop lag fast
  1. Press EMERGENCY: freeze every prop on the map.
  2. Every physics prop stops moving at once. The count is written to the Action Log.

Settings and commands

These server settings are set in Settings > Server Settings. The panel only shows the restart time.

Setting Default Range
kgxat_restart_hour -1 (off) -1 to 23
kgxat_restart_minute 0 0-59
kgxat_dc_cleanup 0 (off) 0-120 minutes
Command Who What it does
kgxat_perf [seconds] Server console, superadmins Times every toolbox hook and net message on the server for 2-60 seconds (default 10), then prints the costliest 25: ms per tick, calls, slowest call.
kgxat_perf_client [seconds] Anyone, on their own game The same for the toolbox hooks on your game (ms per frame). The old name kgxat_hookprofile still works.
kgxat_fast_draw 0/1 Anyone, on their own game 1 (default) = spray paint and rain are drawn in batches; 0 = one by one.

Tips and limits

  • The list only shows the top 15 prop owners.
  • kgxat_perf times hooks and net messages only; timers are not included. One profile runs at a time.
  • Freeze and remove by owner skip players and map-made entities.
  • The emergency freeze skips players and weapons someone is carrying.
  • Every freeze and remove is written to the Action Log.
  • The scheduled restart warns players 10 and 5 minutes before, then uses the normal map change countdown.
  • With kgxat_dc_cleanup set, a leaving player's props are removed after that many minutes, unless they rejoin in time.
