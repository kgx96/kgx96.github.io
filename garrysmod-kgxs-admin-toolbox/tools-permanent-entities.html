Permanent Entities

Make anything permanent (props, ragdolls, NPCs and animals, vehicles, weapons, addon entities): saved with the map, back after every cleanup and restart.

Tool / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Permanent Entities saves an entity with the map. It comes back when the server starts and after every map cleanup. This tool was called Permanent Props in older versions.

Anything can be permanent: props, ragdolls (their pose is kept), NPCs and animals (weapon, health and faction kept), vehicles, weapons lying around and addon entities. The tool saves position, angle, color, material, skin, body groups and frozen state.

Permanent entities are protected. Non-admins cannot pick them up, punt them, use a tool on them or edit them.

Where to find it

Q menu > KGX's Admin Toolbox > World > Permanent Entities.

Toolbox admins can use it. Superadmins can also give it to players in Settings > Player Access. Even then, only admins can use tools on an entity that is already permanent.

Admins only (v3.6.11.3): this tool sets up the server, so it cannot be given to players; it is greyed out in Settings > Player Access.

Controls

Key What it does
Left-click Make the aimed entity permanent
Right-click Make the aimed entity normal again
Reload Save the current position of every permanent entity

Options

Option What it does Default
Come back after being destroyed (s, 0 = only on restart/cleanup) Brings a killed NPC, broken prop or removed entity back after this many seconds, where it was saved. Range 0 to 600. 60
NPCs hold their position (do not walk away) NPCs made permanent with this ticked stay where you placed them. Off
Reset to defaults Puts both options back to their defaults.

While you hold the tool, permanent entities within range have a green outline. The entity under your crosshair shows Permanent or Not permanent.

How to use it

Make a prop permanent
  1. Place the prop where you want it and freeze it if it should stay still.
  2. Set Come back after being destroyed to the delay you want, or 0.
  3. Aim at the prop and left-click.
  4. Run a map cleanup to check: the prop comes back where it was.
Place a guard NPC that stays put
  1. Spawn the NPC and give it its weapon.
  2. Tick NPCs hold their position (do not walk away).
  3. Aim at the NPC and left-click.
  4. If it is killed, it returns after the Come back delay.
Move permanent entities
  1. Move the permanent entities with the physics gun. Only admins can pick them up.
  2. Press reload. The tool saves the new position of every permanent entity on the map.
  3. Without the reload, they return to their old spots on the next cleanup or restart.
Remove an entity from the save
  1. Aim at the permanent entity and right-click.
  2. It stays in the world as a normal entity and no longer comes back.

Settings and commands

Setting What it does Default Range
kgxat_limit_perma Most permanent entities a non-admin player may own (Settings > Limits). 0 = not allowed. 10 0 to 200
kgxat_limits_admins 1 = limits also apply to toolbox admins. Superadmins are never limited. 0 0 to 1

Tips and limits

  • Saved per map in data/kgx_admin_toolbox/permaprops/<map>.json.
  • Left-clicking an entity that is already permanent does nothing. Move it, then reload to save the new spot.
  • These are refused: players, things that are part of the map, a weapon someone is holding, and anything attached to another entity (make the parent permanent instead).
  • Stores, storage containers and teleporters save themselves and are refused. Other toolbox entities (class kgxat_...) cannot be made permanent either.
  • Permanent entities keep Unbreakable, Physgun Block, NPC tags, and Door Maker door and mover settings.
