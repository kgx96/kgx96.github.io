Warp Points

Named teleport spots, saved per map.

Tool / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Warp Points saves named spots on the map. Each warp keeps a position and the direction you faced when you saved it. Anyone sent to a warp faces that way.

Left-click sends a player or entity to the selected warp, and right-click takes you there. Warps are stored on the server and kept after restarts.

A warp can be marked public. Any player can then use it from chat with !warps or !warp <name>. Other warps are admin only.

Where to find it

Q menu > KGX's Admin Toolbox > Functions > Warp Points.

Admin only by default. Superadmins can give it to players or ranks in Settings > Player Access. Rank immunity applies when you send a player.

Public warps: any player can type !warps for a menu or !warp <name>.

Given to a player (v3.6.11.3): Public and their own warps, warp cooldown; never held players.

Controls

Key What it does
Left click Send the aimed player or entity to the selected warp
Right click Warp yourself to the selected warp
Reload Save where you stand as a warp (uses the name field)

The HUD shows "Warp: <name>", or "none selected".

How to use it

Save a warp
  1. Stand where the warp should be and face the way people should look.
  2. Type a name in New warp name. Tick Public if players may use it.
  3. Press Reload, or click Save my position as a warp.
Send a player to a warp
  1. Click the warp in the list to select it.
  2. Aim at the player and left-click.
Let players travel with chat
  1. Select a warp and click Toggle public on selected warp. The Public column shows "yes".
  2. Players type !warps for a menu, or !warp <name>.

Settings and commands

Setting or command What it does Default / range
kgxat_warp_cooldown Seconds a player must wait between public warps (Settings > Server Settings) 5, 0 to 600
kgxat_limit_warps Warps a non-admin player may save (Settings > Limits; 0 = not allowed) 5, 0 to 100
!warps Menu of public warps (also /warps, !warp) -
!warp <name> Go to a public warp; the name is not case-sensitive -

Tips and limits

  • Warps are saved per map in data/kgx_admin_toolbox/warps_<map>.json.
  • Up to 100 warps per map. Names are up to 48 characters.
  • Saving with an existing name replaces that warp.
  • Players cannot use public warps while dead or jailed.
  • If the selected warp was deleted, you get "Warp "<name>" no longer exists."
