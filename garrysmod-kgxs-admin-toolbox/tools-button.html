Button

Buttons that open and close linked doors.

Tool / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

Button places a button that opens and closes the doors linked to it. Anyone presses E on the button and every linked door moves together. You can link Door Maker doors, map doors (func_door, func_door_rotating, prop_door_rotating) and movers from Building > Mover / Elevator.

With an open time above 0, the doors close by themselves after that many seconds. "Closes in N" floats at the button while the countdown runs. Pressing the button again closes the doors early.

Linking is shared with the Keypad tool. You can select a keypad with this tool and link doors to it, and the other way round.

Where to find it

Q menu > KGX's Admin Toolbox > Building > Button.

Admins can use it, and players who are given it in Settings > Player Access. Pressing a placed button with E works for everyone, unless an admin limits it in the button's Access window. Players link only their own keypads and buttons, to their own doors (made with Door Maker, or doors of a property they own), and change only their own.

Given to a player (v3.6.11.3): Link their own buttons to their own doors.

Controls

Key What it does
Left click Place a button (it is selected automatically)
Right click Select a button/keypad, then right-click doors to link/unlink
Reload Apply the current open time, countdown position and sound to the aimed button
E + Reload Remove all links from the aimed button/keypad

While you hold the tool, the screen shows the selected button and how many doors it has linked. The selected button is outlined blue, its linked doors yellow, and other Door Maker doors faint green.

Options

Option What it does Default Range

Attach to the prop it is placed on The button is parented to the prop you click, so it moves with it. On
Server button (admins: saved for the map, belongs to no player) Admins only. The button is saved for the map and has no owner. Off

Silent (no press sound) No sound when pressed. Off

Reset to defaults Puts every option back to its default.

How to use it

Make a button that opens two doors
  1. Make the doors first with Building > Door Maker, or use map doors.
  2. Left-click a wall or prop to place the button. It is selected.
  3. Right-click each door. You get "Linked" for each one.
  4. Press E on the button. Both doors open. Press E again to close them.
Make the doors close by themselves
  1. Set Doors stay open (s, 0 = until pressed again), for example to 5.
  2. Pick a Countdown position.
  3. Aim at the button and press reload. You get "Button: doors close 5 s after opening."
Unlink or relink doors
  1. Right-click the button to select it.
  2. Right-click a linked door to unlink it ("Unlinked"), or a new door to link it.
  3. To remove every link at once, hold E and press reload on the button.
Make a server button (admins)
  1. Tick Server button (admins: saved for the map, belongs to no player).
  2. Place the button and link its doors.
  3. Alt + E on the button opens its Access window: server owned, which ranks or jobs may press it, and a name.

Settings and commands

Setting What it does Default Range
kgxat_limit_buttons Most buttons a limited player may have (Settings > Limits, "Buttons"). 10 0-100

Tips and limits

  • Right-clicking something that is not a door gives "Not a door. Use Building > Door Maker on it first (map doors work as they are)."
  • Right-clicking a door with nothing selected gives "Right-click a button or keypad first to select it."
  • A welded piece of a Door Maker door links the whole door.
  • If any linked Door Maker door is open, a press closes everything; otherwise it opens everything.
  • Remove buttons with undo or the Admin Remover.
  • Admins and superadmins are not limited by kgxat_limit_buttons unless kgxat_limits_admins is on. Superadmins never are.
  • When every door is frozen (kgxat_doors_frozen, Freeze every door in Functions > Keys), buttons do not move Door Maker or map doors.
