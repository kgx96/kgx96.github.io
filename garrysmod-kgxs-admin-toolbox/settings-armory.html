Armory

Weapons and perks players build custom classes from, unlocked for free, by level or with match credits earned in Game Modes matches.

What it does

The Armory is the equipment players build their own classes from, like Create-a-Class in Call of Duty. A class has a Primary, Secondary, Melee, Lethal and Tactical weapon and up to three perks. Game modes with Loadouts set to Players pick a loadout or one of their custom classes offer these classes on the loadout screen next to the admin's preset loadouts.

Every Armory item is free, unlocks at a level (Match stats) or is unlocked for good with match credits. Players earn match credits by playing matches that count (the same rule as Match stats): for finishing, for winning and per kill. What a player unlocked, their credits and their classes are kept per SteamID on every map.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Armory.

Players with Armory access (Settings > Player Access) see the credit settings and can give or take credits; only superadmins edit the items. Players open the Armory (the Create a Class screen) with:

  • !armory (also !classes) in chat,
  • F4 in the hub (between matches, World > Mode Spots hub) when a mode offers custom classes,
  • CREATE A CLASS (K) on a match's loadout screen,
  • the F3 hub's Loadouts tab (CREATE A CLASS / ARMORY),
  • a Talking NPC choice Open the Armory,
  • the console command kgxat_armory.

The Create a Class screen (players)

  • Left: your class slots (EMPTY SLOT = create one) and ARMORY (EVERYTHING). Top right: your credits and level.
  • Right: the class's name and its slots; the Primary card shows the weapon's stat bars. Click a slot to pick an item, right-click to empty it. v3.6.18.1: next to the slots, your character (your Q menu > Player Model with its skin, bodygroups and color) holds the class's primary weapon and turns slowly; drag it to turn it.
  • Picking: every item for that slot with its icon and OWNED / FREE / LEVEL N / N CREDITS; hover shows the stat bars or the perk. Click an owned item to put it in the slot; click a credits item to unlock it (asks first).
  • SAVE CLASS, DELETE CLASS, CLOSE / BACK (F3; while picking an item F3 goes back to the class first).

How to use it

Let players build their own classes
  1. Open Settings > Armory, check the items (or Put the default items back...) and press SAVE ARMORY.
  2. In Utilities > Game Modes, edit a mode: Loadouts = Armory (classes only) or Both (server loadouts and classes). Save the mode.
  3. Players play matches to earn credits, press F4 in the hub (or K on the loadout screen) and build a class.
  4. On the loadout screen their classes show with CUSTOM next to your preset loadouts.
Sell a weapon pack only in one mode
  1. Add the weapons as items with With credits (for good) and a price.
  2. Type the mode's id in Only in these modes.
  3. Set its stat bars if the loadout screen shows "No stats for this item."

Settings and commands

Command Who What it does
kgxat_armory, !armory, !classes Everyone Opens the Armory (Create a Class).
kgxat_credits <name or SteamID> [amount] Armory access, server console Shows a player's credits, or gives (negative takes) credits.

Tips and limits

  • Up to 200 items. Items are saved in data/kgx_admin_toolbox/armory.json; credits, unlocks and classes in armory_players.json.
  • An item keeps its id when you edit its name, price or unlock, so unlocks stay. Changing its weapon, perk or kind makes it a new item: what players bought of the old one does not pass to it. SAVE ARMORY refuses items that are not valid (no weapon class, a class with spaces) and names them.
  • Each perk can be in a class once, even if two items give the same perk. Perks never stack when a class is picked again. Removing an item empties that slot in players' classes; a class with no weapon left for a mode is not offered there.
  • The level is the Match stats level (Utilities > Game Modes > Match stats).
  • Classes never cost match money; paid loadouts (match money) are only the admin's preset loadouts.
