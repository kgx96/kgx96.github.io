Keypad

Code-locked keypads that open linked doors.

Tool / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Keypad places a keypad with a code of 1 to 8 digits. When a player enters the right code, every door linked to the keypad opens. You can link Door Maker doors, map doors and movers from Building > Mover / Elevator.

Doors close again after the open time you set. While they are open, "Closes in N" is shown on the keypad. With an open time of 0 they stay open until closed.

Linking works the same as the Button tool and is shared with it. Five wrong codes lock the keypad for that player for 15 seconds.

Where to find it

Q menu > KGX's Admin Toolbox > Building > Keypad.

Admins can use it, and players who are given it in Settings > Player Access. Entering a code works for everyone, unless an admin limits it in the keypad's Access window. Players link only their own keypads and buttons, to their own doors (made with Door Maker, or doors of a property they own), and change only their own.

Given to a player (v3.6.11.3): Link their own keypads to their own doors.

Controls

Key What it does
Left click Place a keypad with the code from the tool menu
Right click Select a keypad/button, then right-click doors to link/unlink
Reload Apply the current code, open time and timer position to the aimed keypad
Shift + Reload Remove the aimed keypad (yours; admins: any, server keypads too)

While you hold the tool, the screen shows the selected keypad and how many doors it has linked. The selected keypad is outlined blue and its linked doors yellow.

Options

Option What it does Default Range
Look How new keypads look (list below). Set when placed; reload keeps the look. Real keypad (aim at a key + E)
Code (1-8 digits) The code. Anything that is not a digit is dropped. 1234 1-8 digits
Doors stay open (s, 0 = until closed) Auto-close time. 5 0-600
Countdown position Where "Closes in N" is shown: Top, Bottom or Center. Top
Attach to the prop it is placed on The keypad is parented to the prop you click. On
Server keypad (admins: saved for the map, belongs to no player) Admins only. The keypad is saved for the map and has no owner. Off
Reset to defaults Code back to 1234, look back to the real keypad, and every other option to its default.

The looks:

  • Classic keypad: the HL2 keypad model. E opens a number pad window.
  • Button panel: a button model. E opens a number pad window.
  • KGX keypad, square (drawn; aim at a key + E): a drawn touch keypad with a display.
  • Real keypad (aim at a key + E): a drawn wall keypad with a display, lights and 12 keys.

A look whose model the server does not have is marked "(not on this game)" and falls back to the classic keypad.

How to use it

Lock a door with a code
  1. Make the door with Building > Door Maker, or use a map door.
  2. Type a Code (1-8 digits) and set Doors stay open (s, 0 = until closed).
  3. Left-click a wall next to the door. The keypad is placed and selected.
  4. Right-click the door. You get "Linked".
Enter a code as a player
  1. Real or KGX keypad: aim at each key and press E. CLR clears, ENT enters.
  2. Classic keypad or button panel: press E to open the number pad window.
  3. On any keypad you can also look at it from within 150 units and type the code on the keyboard's number pad. Enter = OK, . or Backspace = delete, - = clear.
Change the code of a placed keypad
  1. Type the new code in the panel.
  2. Aim at the keypad and press reload. You get "Keypad code, open time and timer position updated."
Remove a keypad
  1. Aim at the keypad, hold Shift and press reload.
  2. Players can remove their own keypads. Admins can remove any, also server keypads, which are then no longer saved for the map.

Settings and commands

Setting What it does Default Range
kgxat_limit_keypads Most keypads a limited player may have (Settings > Limits, "Keypads"). 10 0-100

Tips and limits

  • Admins: Alt + E on a keypad opens its Access window. It holds the code, which ranks or jobs may use it, whether they get in without the code, and a name.
  • The code is never sent to other players. What you type on the number pad is only shown to you.
  • Hold E and reload with the Button tool to remove all links from a keypad.
  • The Keypad Hacker weapon can open a keypad's doors (Settings > Lockpick & Hacking).
  • When every door is frozen (kgxat_doors_frozen), keypads do not move Door Maker or map doors.
  • Admins and superadmins are not limited by kgxat_limit_keypads unless kgxat_limits_admins is on. Superadmins never are.
