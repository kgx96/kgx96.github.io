Align

Copy rotation and/or position lines from a reference prop.

Tool / Covers v3.6.21.6 / Updated Oct 26, 2026

On this page

  1. What it does
  2. Where to find it
  3. Controls
  4. Options
  5. How to use it
  6. Tips and limits

What it does

Align copies values from one prop onto others. You pick a reference prop, then click the props that should match it. You choose which values to copy: rotation, height (Z), X position and Y position.

Rotation is applied around the prop's center, so the prop turns in place. Every aligned prop is frozen.

The reference is remembered as it was when you picked it. Moving the reference afterwards does not change what the tool copies.

Where to find it

Q menu > KGX's Admin Toolbox > Building > Align.

Admins can use it, and players who are given it in Settings > Player Access.

Given to a player (v3.6.11.3): Their own props only.

Controls

Key What it does
Left click Apply the reference to the aimed prop
Right click Set the aimed prop as the reference
Reload Clear the reference

Options

Option What it does Default
Rotation Copy the reference's angles. On
Height (Z) Copy the reference's height. Off
X position Copy the reference's world X position. Off
Y position Copy the reference's world Y position. Off
Reset to defaults Puts the four boxes back to the defaults above.

How to use it

Line up a row of props at the same height
  1. Tick Height (Z). Untick Rotation if the props should keep their own angles.
  2. Right-click the prop that is at the right height. You get "Reference set".
  3. Left-click each other prop. It moves up or down to the reference's height and is frozen.
Give several props the same rotation
  1. Tick Rotation only.
  2. Right-click the prop with the angle you want.
  3. Left-click the other props. Each one turns in place to match.
Stack props in a straight column
  1. Tick X position and Y position.
  2. Right-click the bottom prop.
  3. Left-click the props above it. They move over the reference and keep their own height.

Tips and limits

  • Left-click without a reference gives "Right-click a reference prop first."
  • Players, NPCs and props attached (parented) to something else cannot be aligned. Edit the parent instead.
  • A Door Maker door, or any piece welded to it, is aligned as one door. It is closed first and still opens correctly afterwards.
  • X and Y are world axes, not the prop's own axes.
  • The reference is not saved. Reload clears it, and it is gone after you rejoin.
