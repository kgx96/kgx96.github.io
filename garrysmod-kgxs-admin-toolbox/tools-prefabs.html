Prefabs

Copy builds (with welds), paste them anywhere, save them by name.

Tool / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Prefabs copies a build into your clipboard and pastes it somewhere else. Right click copies a prop and everything constrained to it. Reload copies every prop inside a radius.

Left click pastes the clipboard where you aim, turned to the way you are facing. The build keeps its layout, and its lowest point sits on the spot you aim at.

You can save the clipboard under a name. Saved prefabs are kept on the server and work on every map.

Where to find it

Q menu > KGX's Admin Toolbox > Building > Prefabs.

Admins can use it, and players who are given it in Settings > Player Access. Only admins can delete saved prefabs.

Given to a player (v3.6.11.3): Their own props; saves up to 10 prefabs of their own.

Controls

Key What it does
Left click Paste the copied build where you aim (turned to face like you)
Right click Copy the aimed prop and everything constrained to it
Reload Copy every prop inside the radius

While the tool is out, the text under the crosshair shows "Clipboard: N props" or "Clipboard empty". A red sphere and a yellow ground ring show the copy radius at your crosshair.

Options

Option What it does Default
Copy radius (reload) Size of the sphere reload copies from. Slider 16 to 2048. 200
Paste height Pastes this many units above the aimed spot. Slider 0 to 1024. 0
Paste everything frozen Freezes every pasted prop. Off keeps each prop's frozen state from the copy. On
Reset to defaults Puts the three options above back to their defaults.
Saved prefabs

The list shows Name and Props for every prefab saved on the server.

Control What it does
Prefab name (text box) The name to save under. Clicking a row fills it in.
Save clipboard as this name Saves your clipboard under the typed name.
Load selected into clipboard Loads the selected prefab so left click pastes it. Double-clicking a row does the same.
Delete selected Deletes the selected prefab after you confirm. Admins only.
Clear clipboard Empties your clipboard.
Refresh list Reloads the list from the server.

How to use it

Copy a welded build and paste it elsewhere
  1. Right-click any prop of the build. You get "Copied N props, N welds. Left-click to paste."
  2. Walk to the new spot and face the way the build should face.
  3. Left-click the ground. The build appears, welded as before.
Copy everything in an area
  1. Set Copy radius (reload) so the sphere covers the build.
  2. Aim at the middle of the build and press reload.
  3. Left-click where it should go.
Save a build for later
  1. Copy the build with right click or reload.
  2. Type a name in Prefab name and press Save clipboard as this name.
  3. On any map, select it in the list, press Load selected into clipboard, then left-click to paste.

Settings and commands

Setting What it does Default Range
kgxat_limit_prefab Most props per paste for limited players (Settings > Limits). 0 = not allowed. 30 0 to 200
kgxat_cap_area_radius Largest copy radius for limited players. 512 0 to 16384

Tips and limits

  • Only spawned props (prop_physics) are copied. Map props and Door Maker doors are skipped.
  • Up to 200 props per copy.
  • Copied: model, position, angle, color, material, skin, frozen state and welds. Other constraints, doors and wiring are not copied.
  • Reload only copies props you are allowed to touch under prop protection.
  • Undo removes a whole paste at once. Pasted props belong to you.
  • Players who are not admins can paste at most once every 2 seconds.
  • Names are saved in lowercase, spaces become underscores, other symbols are dropped, up to 40 characters.
  • Files are stored in data/kgx_admin_toolbox/prefabs/<name>.json.
  • The clipboard is not saved. It is empty after you rejoin.
