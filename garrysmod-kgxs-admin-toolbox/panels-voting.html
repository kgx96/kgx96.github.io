Voting

Start polls, map votes and server mode votes, manage the map pool, and set rock the vote, nominations, kick and mute votes and elections.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

Voting runs up to three votes at once, tagged A, B and C. Each vote shows as a box on the left of every screen. Map votes show as a row of map thumbnails at the top.

Players vote with the number keys, which go to the first vote they have not voted in yet. They can also type !vote <number> or !vote <A/B/C> <number>. The box the number keys go to is blue.

From this panel you start polls, map votes and server mode votes, end or cancel running votes, and keep the map pool. Superadmins also set rock the vote, nominations, automatic map votes, kick and mute votes and job elections.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Voting.

  • Starting, ending and cancelling votes: admins, or players ticked for Voting in Player Access.
  • Map pool and Settings: superadmins only (the controls are greyed out for others).
  • Player chat commands work for everyone (see below).

How to use it

Ask the players a question
  1. Open Utilities > Voting.
  2. Set Vote time (s).
  3. Type the question under Poll and fill in the options.
  4. Click Start poll. The result is announced on every screen when it ends.
Let players pick the next map
  1. Click Start a map vote from the map pool (nominations first).
  2. Players press the number of a thumbnail.
  3. When time runs out, the winner loads after 10 seconds.
Offer a short list of maps
  1. Search the map list and Ctrl+click the maps you want.
  2. Untick Add "Stay on this map" if the map must change.
  3. Click Start a map vote with the picked maps.
Change maps automatically
  1. As a superadmin, set Automatic map vote after (minutes, 0 = never), for example 45.
  2. Click Apply the numbers above.
  3. After 45 minutes on a map a vote starts by itself with an "Extend the map" option while extends are left.

Settings and commands

Command Who What it does
!vote <number> Everyone Vote in the first vote you have not voted in.
!vote <A/B/C> <number> Everyone Vote in a given vote. You can change your vote.
!rtv or !rockthevote Everyone Ask for a map vote. Enough players start one.
!nominate <map> Everyone Put a pool map into the next map vote. One nomination per player.
!nominations Everyone List the nominations.
!maps Everyone List the map pool, with maps on cooldown marked.
!votekick <name> [reason] / !votemute <name> [reason] Everyone, when on Start a kick or mute vote.
kgxat_vote <number> or kgxat_vote <A/B/C> <number> Everyone Console version of !vote.

Tips and limits

  • A fourth vote is refused until one of the three ends. Only one map vote and one mode vote run at a time.
  • A map vote with picked maps still holds at most kgxat_mapvote_maps maps.
  • Maps played in the last few map changes are left out of map votes and nominations unless there are not enough others.
  • When the players choose to stay, or nobody votes, !rtv is blocked for 5 minutes.
  • v3.6.14: Utilities > Game Modes > Next match runs its own votes between matches: "Which mode next?" (Game Modes modes) and, every N matches, a map vote. They use one of the three vote slots like any vote.
  • Kick and mute votes never target toolbox admins, the target cannot vote, and the starter votes yes.
  • The time between one player's kick or mute votes is kept by SteamID, so rejoining does not reset it. A mute vote that passes after its target left applies when they come back.
  • The map pool and map history are saved in data/kgx_admin_toolbox/mapvote.json. Nominations and rock the vote reset after each map vote.
  • Thumbnails come from maps/thumb/<map>.png. Maps without one show a grey box.
  • Number keys only vote while a vote is waiting for you; otherwise they switch weapons as usual.
