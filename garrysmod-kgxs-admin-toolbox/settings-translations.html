Translations

The toolbox's player screens in six languages (English, Español, Deutsch, Français, Русский, Português (Brasil)); the server's default language, each player's own pick, and the owner's edits.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Translations (v3.6.19) shows the toolbox's player screens in each player's language:

  • the Toolbox HUD and the F3 hub (tabs, columns, keys, stats);
  • the loadout screen (F4) and Create a Class;
  • votes (the HUD, questions, options and results);
  • the match HUD: rounds, the scoreboard, end screens, objectives, the kill feed, Waves, buy stations, Traitors / Murder, Hide and Seek, Gun Game, Infection, Juggernaut, Duels and Race;
  • the XP popup and the match and vote messages in chat and on screen.

Built-in languages: English, Español, Deutsch, Français, Русский and Português (Brasil). Text with no translation stays English. Admin panels stay English for now; they follow in later patches.

The server sends each message as English text with its values (a name, a number), and each player's game shows it in that player's language. Two players in the same match can read the same message in two languages. Server logs, the Action Log, stats and saved files stay English.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Translations. Everyone can open it and read the phrases. Only the server owner (kgxat_owner in the server console; superadmins while no owner is set) changes phrases and languages. Superadmins set the server's default language.

Each player picks their own language in Settings > Display (themes) > Language.

How to use it

Set the server's language
  1. Open Settings > Translations.
  2. In Server default language, pick the language, or auto so every player gets their own game language.
  3. Players who picked a language in Settings > Display keep theirs.
Fix a translation
  1. Pick the Language to edit and type a word of the phrase in Find a phrase.
  2. Double-click the line, type your text and press OK. Every player using that language sees it right away; players who join later get it too.
  3. To undo, right-click it > Back to the built-in text.

You can also edit English to change the wording on your server (for example "Scoreboard" to "Leaderboard").

Add a language
  1. Press Add a language of your own..., type the code and the name.
  2. Pick it in Language to edit and fill in the phrases (the most seen first: the HUD, F3 and the match messages).
  3. To share it with another server, press Copy this language as JSON and save it there as data/kgx_admin_toolbox/lang_<code>.json.

Settings and commands

Command / file What it does
kgxat_language Server: the default language: en, es, de, fr, ru, pt_br, a code you added, or auto. With KGX Core (v3.6.21.6) it is the same as kgx_language, the default of every KGX addon.
kgxat_lang Player: empty = the server's default, auto = your Garry's Mod language, or a code. Set in Settings > Display. With KGX Core it is the same as kgx_lang.
data/kgx_admin_toolbox/lang_<code>.json The owner's edits for a language: {"English text": "translation"}. A file put there loads when the map starts.
data/kgx_admin_toolbox/lang_custom.json The languages you added: {"code": "Name"}.

Tips and limits

  • The built-in translations come with the addon and update with it. Your edits stay and win over them.
  • Player names, weapon names from other addons, map names and text you typed yourself (mode names, loadout names, vote questions) are shown as they are.
  • Some short pieces built by the game itself (like "5 minutes" in a cooldown message) stay English.
  • Titles shown in capitals (class names, role names) are made upper case for Cyrillic and accented letters too.
