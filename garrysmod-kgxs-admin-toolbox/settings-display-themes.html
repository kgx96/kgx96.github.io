Display (themes)

Your language for the toolbox's player screens, and your own dark mode for the Q and C menus or every game menu, with color themes, brightness, colored text and tool tips.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Display sets how the game's menus look for you. Dark mode can cover the spawn menu (Q) and context menu (C), or every game menu and window.

With dark mode on, you can pick a color theme, make it lighter or darker, and turn colored text on or off. A preview strip shows the theme's colors, even while dark mode is off.

v3.6.19: Language picks the language of the toolbox's player screens for you (the HUD, F3, the loadout screen, Create a Class, votes and the match screens and messages).

v3.6.21.6: with KGX Core installed (a required item), your language and the NEW / UPDATE tags are shared with every KGX addon: picking a language here also sets it in Q menu > Utilities > KGX > KGX Core, and the other way round. A line under the language says whether they are shared, or that KGX Core is missing.

These are your own settings, saved only on your computer. Nobody else sees them.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Display (themes).

Everyone can use it. A key to switch dark mode on and off can be set in Settings > Keybinds.

How to use it

Play in your language
  1. Open Settings > Display (themes).
  2. In Language, pick your language, or My Garry's Mod language.
  3. Open F3 or F4: the screens are in that language. Admin panels stay English for now.
Turn on dark mode
  1. Open Q menu > KGX's Admin Toolbox > Settings > Display (themes).
  2. In Dark mode, pick Spawn menu (Q) and context menu (C).
  3. To darken every game menu and window too, pick Every game menu and window.
Change the look
  1. Pick a Theme. The preview strip changes.
  2. Move Brightness (higher = lighter) until it reads well.
  3. Untick Colored text (category headers, hovered and selected tools) for a plainer look.
Switch dark mode with a key
  1. Open Settings > Keybinds.
  2. Set Dark mode: on/off (F6 recommended).
Turn the hover preview off and on
  1. Untick Hovering a model, weapon, entity, NPC or vehicle in a list or the spawn menu shows it at the cursor, or press F7 (Settings > Keybinds, Hover preview: on/off). The key also works with the spawn menu open, not while you type in a text box.
  2. A message shows "Hover preview on" or "Hover preview off".
Check what the hover preview can show
  1. Make sure the hover preview is on.
  2. Open more spawn menu categories first, so their icons are built.
  3. Press Scan for previews (what the hover preview can show).
  4. The window lists counts per kind and the first 60 items without a model or icon. The same report is printed in your console.

Settings and commands

Client convar Default What it does
kgxat_darkmode 0 0 = off, 1 = spawn and context menu, 2 = every game menu.
kgxat_darkmode_theme graphite Theme id: graphite, slate, ocean, forest, purple, crimson, amber, midnight.
kgxat_darkmode_bright 0 Brightness, -20 (darker) to 40 (lighter).
kgxat_darkmode_colortext 1 Colored text.
kgxat_tool_tips 1 Tool tips in the tool list.
kgxat_version_text_show 1 The version line at the bottom right.
kgxat_darkmode_key 0 Dark mode toggle key (Settings > Keybinds).
kgxat_prop_preview 1 Hover preview on (1) or off (0).
kgxat_prop_preview_key 0 Hover preview toggle key (Settings > Keybinds, F7 recommended).

Tips and limits

  • Theme, brightness and colored text need dark mode on.
  • Some addon menus draw their own colors and stay as they are.
  • Right-click any tool in the tool list to add it to your favorites.
  • The reset window in Server Settings can also reset your display options ("My tool settings and display options (on this computer)").
