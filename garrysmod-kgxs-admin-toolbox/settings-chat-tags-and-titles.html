Chat Tags & Titles

Give each rank a chat tag and name color, such as [VIP] in gold, and show player titles or rank tags above heads.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

This panel gives each rank a tag and a name color in chat, for example [VIP] in gold. A player's chat line then shows the tag in its color, then their name in the rank's name color or their team color.

Titles are shown above a player's head. You set a player's title in the Player Manager (Set title...). Players without a title can show their rank tag above their head instead.

Chat tags turn off automatically while DarkRP runs, because DarkRP formats chat itself.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Chat Tags & Titles.

Only superadmins can change these settings. Everyone else sees "Only superadmins can change these settings." with the controls greyed out. Titles are set from the Player Manager: right-click a player > Set title....

The panel

Switches

Each applies as soon as you tick it.

Option What it does Default
Rank tags and name colors in chat Turns chat tags on. On
Show titles above heads Shows player titles above their heads. On
Show the rank tag above heads of players without a title Shows the rank tag, in its color, for players with no title. Off
Tags per rank
Option What it does Default
List: Rank, Tag Every rank that has a tag. Click one to load it into the form.
Rank The rank to edit. Type a name or pick one. user
Scan ranks (admin mod, toolbox ranks) Fills the rank list again from your admin mod and the toolbox's ranks.
Tag (e.g. [VIP], empty = only the name color): The tag text, up to 24 characters. empty
Tag color: Color picker for the tag. gold
Name in the team/job color (not the color below) Ticked: the name keeps the team or job color. On
Name color: Color picker for the name, used when the box above is unticked. white
Set the tag for this rank Saves the tag, tag color and name color for the rank.
Remove the tag of this rank Removes the rank's tag.

How to use it

Give VIPs a gold tag
  1. Open Q menu > KGX's Admin Toolbox > Settings > Chat Tags & Titles as a superadmin.
  2. Pick vip in Rank. If it is missing, press Scan ranks (admin mod, toolbox ranks).
  3. Type [VIP] in the tag box and pick gold in Tag color:.
  4. Press Set the tag for this rank. VIP chat lines now start with [VIP].
Color a rank's names instead of a tag
  1. Pick the rank and leave the tag box empty.
  2. Untick Name in the team/job color (not the color below) and pick a Name color:.
  3. Press Set the tag for this rank.
Give a player a title
  1. Open the Player Manager and right-click the player.
  2. Choose Set title..., type the title, and press OK. Leave it empty to remove it.
  3. The title shows above their head while Show titles above heads is on.

Settings and commands

Convar Default What it does
kgxat_chat_tags 1 Rank tags and name colors in chat.
kgxat_overhead_titles 1 Titles above heads.
kgxat_overhead_ranks 0 Rank tag above heads of players without a title.

Tips and limits

  • Dead players' lines start with DEAD, team chat with (TEAM), before the tag.
  • Titles are up to 40 characters and are kept per SteamID, so they come back when the player rejoins.
  • Above-head text is drawn only within about 700 units, and not for yourself.
  • Auto-rank promotion messages use the rank's tag text as its name (Settings > Playtime & Auto-Ranks).
  • Tags are saved in tags.json and titles in titles.json.
