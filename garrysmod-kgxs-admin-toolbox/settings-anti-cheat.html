Anti-Cheat

Server-side checks for speed, flying, noclip, teleports, aim snaps and net spam, with strikes, a live list, scans and optional kicks.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

Anti-Cheat runs checks on the server and gives a strike for each hit. It looks for speed on the ground, flying, noclip while noclip is off for that player, teleport jumps, aim snaps while shooting and net message spam. It is off by default (kgxat_ac 0).

A strike is written to the Action Log, Discord logs and the player's history, and shown to admins. You can also kick a player automatically after a set number of strikes. Each kind of check gives at most one strike every 10 seconds per player.

These checks are heuristics. Jetpacks, sprint mods and other movement addons can trigger them, so start with kicks off and watch the live list. Teleports and noclip set by any addon's Lua (the toolbox, ULX, DarkRP and others) and map teleporters are never counted. Client-side cheats that do not change what the server sees, such as wallhacks or ESP, cannot be detected.

The page also holds the toolbox net budget (kgxat_net_budget). It limits how many toolbox net messages one player may send per second and works even with the anti-cheat off. v3.6.21.6: with KGX Core installed it is the same setting as kgx_net_budget, and the limit counts every KGX addon's messages from that player together (the toolbox's 100 is kept when Core is added).

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Anti-Cheat.

  • Only superadmins can change the settings. Other viewers see "Only superadmins can change these settings." and the controls are greyed out.
  • The live list, Scan now, and the strike commands work for toolbox admins.
  • Server console: kgxat_acscan prints the scan report.

How to use it

Turn the anti-cheat on safely
  1. As a superadmin, open Settings > Anti-Cheat.
  2. Tick Anti-cheat on. Leave Kick at this many strikes (0 = never) at 0.
  3. Play normally for a while and watch the live list and the strike messages.
  4. If a movement addon causes false strikes, raise its threshold or untick that check, then press Apply the numbers above.
  5. When you trust the results, set a kick count and press Apply the numbers above.
Test each check with a Test Dummy
  1. Tick Anti-cheat on.
  2. Spawn a Test Dummy in an open area. Shift + right-click it > Act like a cheater.
  3. Pick speed, flying, teleport, noclip or aim snaps. Within seconds the dummy gets a strike and its row turns red.
  4. Pick Play fair again to stop.

Noclip without asking only gives a strike when sbox_noclip is 0. If you set a kick count, the dummy is removed at that strike count.

Get a report of every player
  1. Press Scan now (report of every player).
  2. The window lists which checks are on, whether admins are checked and the kick count.
  3. Players with 3 or more strikes show as BAD, fewer as WARN, with their last 5 strikes.
  4. A line also names any other addon that already wrapped net messages (another anti-cheat or net limiter).

Tips and limits

  • Players are not checked while dead, in a vehicle, held by a physgun, spectating, parented to something, or for a short grace time after spawning or a Lua teleport.
  • Speed is not checked while standing on a moving object or in deep water.
  • A speed strike needs 1.5 seconds over the limit. The limit is run speed times the factor, plus 50.
  • Admins are always allowed to noclip, so they never get a noclip strike.
  • The anti-cheat's SetPos, SetMoveType and net hooks are only in place while kgxat_ac is 1. Turning it off takes them out, no restart needed.
  • Ignore messages above the limit can break addons that send many messages at once. Leave it off unless you need it.
  • The toolbox net budget drops extra toolbox messages and logs it at most once a minute per player.
  • Strikes are kept on the player for the current session only.
