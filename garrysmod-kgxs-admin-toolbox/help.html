Help inside the game

The README and the patch notes ship with the addon: Q menu > KGX’s Admin Toolbox > Settings > Patch Notes & README, or the console commands kgxat_readme and kgxat_patchnotes.

KGX Core

The shared library the KGX addons run on, and its API for addon developers: KGX Core (v1.0.0).

Ask or report

Found a bug? Report it on GitHub (a short form: version, gamemode, what happened). Questions: the FAQ, or a comment on the Steam Workshop page with your toolbox version.
