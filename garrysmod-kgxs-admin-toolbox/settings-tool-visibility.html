Tool Visibility

Hide toolbox tools, panels and C menu entries, or show them only to chosen ranks, jobs or license holders.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Tool Visibility hides any tool or panel of the toolbox's Q menu tab. It also covers the C menu's ATB window and its right-click options. An entry can be hidden for everyone, or shown only to some ranks, jobs or license holders. A player who matches any one of them sees it.

Admins always see entries that are limited to ranks, jobs or licenses. An entry marked hidden is hidden for everyone. Hidden entries leave the Q menu, Find a tool and Favorites.

Players cannot use a tool hidden from them, even when Player Access ticks it. The ATB icon leaves the C menu for players who may not see the ATB window.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Tool Visibility.

Only superadmins change these rules. Everyone else sees the buttons greyed out, with the line "Only superadmins change these." The server also refuses a save from anyone who is not a superadmin.

The panel

Option What it does
Search Filters the list by name, category or internal key.
List: Name, Where, Shown Every entry. Where is its Q menu category, or "C menu". Shown reads "everyone", "hidden for everyone", or "only ranks: ...; jobs: ...; licenses: ...". Ctrl or Shift + click selects several.
Status line The selected entry and its rule, or how many entries are selected.
Hidden for everyone Hides the selected entries from everyone.
Only for these ranks... Opens a pick window of every rank.
Only for these jobs... Opens a pick window of toolbox jobs and teams.
Only for these licenses... Opens a pick window of every license.
Shown to everyone again (the selected entries) Removes the rule from the selected entries.
Save Saves every rule on the server and sends it to all players.

Changes in the panel are not applied until you press Save.

With one entry selected

The pick window opens with that entry's current list ticked. Untick a line to take it away.

With several entries selected

Hidden for everyone and Shown to everyone again apply to all of them. In a pick window, the lines you tick are added to each entry's list; nothing is removed.

The pick window
Control What it does
Search... Filters the lines.
Only the ticked Shows only ticked lines.
Double-click a line Ticks or unticks it. A green check mark shows ticked lines.
Tick selected / Untick selected Ticks or unticks the selected lines (Ctrl or Shift + click selects many).
Tick all shown Ticks every line the search shows.
Untick all Unticks everything.
Done Uses the ticked lines.

How to use it

Hide a tool from everyone
  1. Open Q menu > KGX's Admin Toolbox > Settings > Tool Visibility as a superadmin.
  2. Search for the tool and select it.
  3. Tick Hidden for everyone.
  4. Press Save. The Q menu updates when it opens again.
Show a tool only to one rank
  1. Select the tool in the list.
  2. Press Only for these ranks..., double-click the rank, then press Done.
  3. Press Save. Shown now reads "only ranks: <rank>".
Limit several entries at once
  1. Ctrl + click each entry in the list.
  2. Press Only for these jobs... (or ranks, or licenses), tick the lines, then press Done. They are added to every selected entry.
  3. Press Save.
Hide the ATB window from players
  1. Select ATB window (C menu) (Where: C menu).
  2. Tick Hidden for everyone, or limit it to ranks, jobs or licenses.
  3. Press Save. The ATB icon leaves the C menu for those players.

Tips and limits

  • This panel and Find a tool are never in the list and can never be hidden.
  • Rules are saved in data/kgx_admin_toolbox/tool_visibility.json.
  • Hidden for everyone also hides the entry from admins' Q menu. Admins can still use a hidden tool.
  • Tool Visibility only hides and blocks; it does not give access. Give tools with Settings > Player Access, or with a license: Settings > Licenses (Tool License).
  • The C menu is not rebuilt while it is open; the ATB icon changes the next time.
  • If a rank or job is missing from a pick window, use the Scan & update button in Server Settings.
