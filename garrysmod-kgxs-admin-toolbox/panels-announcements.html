Announcements

Show a large message in the middle of every player's screen, or privately on one player's screen.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Announcements shows a large message centered near the top of the screen, with a short sound. Send it to everyone, or privately to one player.

A private message shows "Private message from (your name)" above the text, only on that player's screen. Every announcement and private message is written to the Action Log.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Announcements.

Toolbox admins can use it. Players can get it through Settings > Player Access with the Announcements tick. Players with the Player Manager tick can send private messages, but not announcements to everyone.

Player Manager also has Send private message... in its right-click menu.

The panel

Option What it does Default
Send to Everyone, or one player listed as "(name) (private)". Everyone
Refresh player list Reloads the players in Send to.
Message box The text to show. Up to 200 characters. Empty
Seconds on screen How long the message stays (2-30). 6
Also print in chat Also adds the message to chat. On
Send Sends the message.
Reset to defaults Clears the message, sets 6 seconds, ticks chat and reloads the player list.

In chat, an announcement shows as [Announcement] and a private message as [PM from (name)].

How to use it

Announce to everyone
  1. Open Utilities > Announcements.
  2. Leave Send to on Everyone.
  3. Type the message, for example "Event starts in 5 minutes".
  4. Set Seconds on screen and press Send.
Message one player privately
  1. Press Refresh player list if the player joined recently.
  2. Pick "(name) (private)" in Send to.
  3. Type the message and press Send. You get a "Private message sent to (name)." notice.

Tips and limits

  • Line breaks in the message become spaces.
  • You can send once every 2 seconds. Sending faster shows "Wait a moment before sending again."
  • If the chosen player has left, you see "That player has left. Refresh the list."
  • A new announcement replaces the one on screen.
  • For messages on a timer, use Utilities > Auto Messages or Settings > Scheduler.
