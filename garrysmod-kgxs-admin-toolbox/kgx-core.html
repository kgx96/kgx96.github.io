What it is

KGX Core is the shared library every KGX addon runs on: the addon registry, safe networking, the data layer, staff permissions, a settings registry, translations, notifications, the action log and the UI kit. On its own it adds one page to the Q menu and nothing else. KGX addons that need it list it as a required item on the Workshop, so subscribing to one of them subscribes you to Core as well.

Core is a dependency, not a framework: each addon keeps its own ConVars, data files and gameplay and calls KGXCore.* for the plumbing. A public function is never removed or renamed inside a major version; a removal is deprecated for one minor release first.

Install

Subscribe on the Steam Workshop, or extract the kgx_core folder into garrysmod/addons/. The resulting path must be garrysmod/addons/kgx_core/lua/autorun/_kgx_core.lua. The host installs it; its Lua is sent to joining clients. The leading underscore sorts it ahead of the other KGX autoruns; addons never rely on that and wait for KGXCore.OnReady instead.

If an addon needs a newer Core than the one installed, it is not loaded, the console says which version it needs, and superadmins get a chat line on join. Nothing errors.

Who is staff. With an admin mod that supports CAMI (ULX, SAM, sAdmin and others) the privilege KGX Addons decides (admin and up by default). Without one, admins and superadmins are staff, plus the ranks in kgx_allowed_ranks. kgx_superadmin_only overrides everything.

Data and the update check

Every KGX data file lives in garrysmod/data/kgx_core/<addon>/*.json. A write goes to _tmp/ first and its size is checked; the old file moves to _bak/; then the new file moves into place. A crash or a full disk mid-save leaves the old file or the backup, never half a file. A file that does not parse is moved to _broken/ and the last good copy is used.

Update check. The server fetches versions.json from this site 30 seconds after the map loads and every 6 hours, keeps the answer in data/kgx_core/kgx_core/versions.json, and sends it to players for the menu. If outgoing HTTP is blocked on the server the note never appears and nothing else is affected.

For addon developers: getting started

An addon registers once, inside KGXCore.OnReady, and names the lowest Core version it needs. If Core's autorun has not run yet it boots on the KGXCore_Ready hook; a server without Core at all sees one warning on the first tick instead of errors.

-- lua/autorun/my_addon.lua
if SERVER then AddCSLuaFile() end

local function boot()
    local ok = KGXCore.Register({
        id       = "my_addon",        -- a-z, 0-9 and _, starting with a letter
        name     = "My Addon",
        version  = "1.0.0",
        needs    = "1.0.0",           -- lowest Core version
        workshop = "1234567890",      -- Workshop item id (the menu links to it)
    })
    if not ok then return end         -- Core too old, or the id is taken: already warned

    -- settings a superadmin may change from a panel
    local speed = CreateConVar("my_speed", "650", bit.bor(FCVAR_ARCHIVE, FCVAR_REPLICATED), "Speed.", 100, 1500)
    KGXCore.Setting("my_addon", speed, {min = 100, max = 1500, new = "1.0.0"})

    if SERVER then
        KGXCore.Receive("my_addon_go", function(len, ply)
            KGXCore.Action("my_addon", ply, nil, "pressed go")
            KGXCore.NotifyL(ply, "Done, {1}!", NOTIFY_GENERIC, {ply:Nick()})
        end, {rate = 0.5})
    else
        KGXCore.AddPhrases("my_addon", "es", {["Done, {1}!"] = "Listo, {1}!"})
        hook.Add("PopulateToolMenu", "MyAddon_Menu", function()
            spawnmenu.AddToolMenuOption("Utilities", "KGX", "my_addon", "My Addon", "", "", function(panel)
                local check, slider, applyButton = KGXCore.SettingRows(panel, LocalPlayer():IsSuperAdmin())
                slider("my_speed", KGXCore.L("Speed"))
                applyButton()
            end)
        end)
    end
end

if KGXCore then
    KGXCore.OnReady(boot)
else
    -- Core's autorun (_kgx_core.lua) normally runs first; if not, boot when it is ready.
    hook.Add("KGXCore_Ready", "MyAddon_Boot", function() hook.Remove("KGXCore_Ready", "MyAddon_Boot") boot() end)
    timer.Simple(0, function() -- after every autorun has run: Core really is missing
        if KGXCore then return end
        ErrorNoHalt("[My Addon] KGX Core is not installed. Subscribe to it on the Workshop.\n")
        if SERVER then
            hook.Add("PlayerInitialSpawn", "MyAddon_NoCore", function(ply)
                timer.Simple(10, function()
                    if IsValid(ply) and ply:IsSuperAdmin() then
                        ply:ChatPrint("[My Addon] KGX Core is missing; the addon is not loaded.")
                    end
                end)
            end)
        end
    end)
end

Another KGX addon as a dependency: KGXCore.Require("throw_equipped", "1.2.0") is true when it is installed at that version or newer.

API reference

Registry (sh_core.lua)

FunctionRealmDoes
KGXCore.Register(info)sharedinfo = {id, name, version, needs, workshop, author}. Stores the addon in KGXCore.Addons[id], checks needs against KGXCore.Version, prints one console line, runs KGXCore_Registered(row). Returns false (and warns) when Core is too old, the id is invalid or taken by another addon.
KGXCore.Require(id, minVersion)sharedTrue when another KGX addon is registered at minVersion or newer.
KGXCore.OnReady(fn)sharedRuns fn now if Core is loaded, otherwise once KGXCore_Ready fires. Errors in fn are printed, not thrown.
KGXCore.Installed()sharedThe registered addons, sorted by name: {id, name, version, needs, workshop, author}.
KGXCore.VersionBelow(a, b) / VersionAtLeast(have, want) / VersionOK(v)sharedNumeric per part: 1.2.0 < 1.10.0. VersionOK: looks like 1.2.0 (more parts allowed).
KGXCore.Version, KGXCore.Name, KGXCore.Ready, KGXCore.ProblemssharedCore's version string; "KGX Core"; true once loaded; the warnings superadmins get on join.

Networking (sh_net.lua)

FunctionRealmDoes
KGXCore.Receive(name, fn, opts)servernet.Receive with the checks every KGX message gets before fn(len, ply) runs: a valid player, the message under opts.maxBytes (default 64 KB), the player inside kgx_net_budget, opts.rate seconds since their last one of this message, opts.auth(ply) true. Errors in fn are printed with their stack and never stop other messages.
KGXCore.SendPayload(name, target, data)serverdata as compressed JSON to a player, a list, or everyone (nil). Over 65,000 bytes is refused and logged. Add the name with util.AddNetworkString first.
KGXCore.SendPayloadToServer(name, data)clientThe same, upward.
KGXCore.ReadPayload(maxOut) / ReadPayloadText(maxOut)sharedInside a receiver: the table / the JSON text, or nil. maxOut caps what is unpacked (default 1 MB).

Data (sv_data.lua)

FunctionRealmDoes
KGXCore.DataRead(id, file)serverdata/kgx_core/<id>/<file>.json as a table, or nil. A broken file is moved to _broken/ and the _tmp/ or _bak/ copy is used.
KGXCore.DataWrite(id, file, data, pretty)serverWrites it safely (temp, backup, move). Returns true when saved.
KGXCore.DataDelete(id, file)serverRemoves the file and its copies.
KGXCore.DataSaver(id, name, every, fn)serverfn runs every `every` seconds (nil = only at shutdown) and once more at ShutDown. The same name again replaces it.

Permissions (sh_perms.lua)

FunctionRealmDoes
KGXCore.Allowed(ply)sharedStaff: kgx_superadmin_only, else the ranks in kgx_allowed_ranks, else CAMI (privilege KGX Addons), else IsAdmin(). Cached one second per player; KGXCore.AllowedReset(ply) clears it.
KGXCore.Check(admin, target, needPlayer)serverGuard before an action: a valid admin, a real target, and a player when needPlayer is set (the admin is told otherwise).
KGXCore.HasAccess(ply, id, key)sharedPer-addon keys: staff always; else the key is open to players or to the player's rank.
KGXCore.SetAccess(id, key, players, ranks)serverSets one key (players = everyone may; ranks = a list or set), saves access.json and sends it to clients (KGXCore_AccessChanged).
KGXCore.AllRanks(extra)shareduser, admin, superadmin, the admin mod's groups, the ranks of players online, plus extra; sorted.

Settings (sh_settings.lua)

FunctionRealmDoes
KGXCore.Setting(id, cvar, opts)sharedRegisters a server ConVar a superadmin may change from a panel. opts: kind (bool | number | string; number when min is set, else bool), min, max, decimals, maxLength, pattern, new = "1.2.0", updated = "1.2.0". Only registered ConVars are accepted by the kgx_setcvar / kgx_setnum / kgx_setstr messages.
KGXCore.MarkNew(name, version) / MarkUpdated(name, version)sharedNEW / UPDATE marks for controls that are not ConVars, keyed by any name.
KGXCore.SettingsOf(id)sharedThe registered settings of one addon.

Translations (sh_lang.lua)

FunctionRealmDoes
KGXCore.AddPhrases(id, code, table)sharedAn addon's phrases for one language: {["English"] = "Texto"}. Codes: es, de, fr, ru, pt_br.
