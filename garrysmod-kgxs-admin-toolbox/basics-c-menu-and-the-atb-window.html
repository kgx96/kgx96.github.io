C Menu and the ATB Window

Hold C for the ATB window of quick admin functions, and right-click anything in the C menu for the toolbox's ATB options.

Guide / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

The toolbox adds two things to the C menu (the context menu you get by holding C). The first is the ATB icon, which opens a window of quick functions. The second is an ATB entry when you right-click a player or entity.

Admins get the full window: buttons for themselves, the server and the players. Non-admins get a smaller version with their own shortcuts, such as jobs, backpack and third person.

The right-click ATB submenu is for admins. It lists what the toolbox can do to the thing you clicked, so you do not need to switch tools.

Where to find it

Hold C and click the ATB icon on the C menu desktop. The console command kgxat_atb opens the same window without the C menu.

Who can use it:

  • The admin window and the right-click ATB options need toolbox admin rights and kgxat_cmenu 1 (the default).
  • Players without admin rights get the player version of the window.
  • Settings > Tool Visibility can hide the window or the right-click options for some or all players.

The ATB window

The window title is ATB - quick admin functions for admins and ATB for players. You can resize it. It remembers the last tab you used.

HUD shortcuts (v3.6.21.3)

Put any ATB button on your screen as a shortcut:

  1. Hold C and open the ATB window.
  2. Drag a button out of the window and let go where you want it. (Or right-click the button > Add to my HUD.)
  3. The shortcut stays on your screen. Hold C to click it; it runs the same as the button (risky ones still ask first).

Each button can be on your HUD once: dropping it again moves it. Without C held the shortcuts are only drawn; while you hold C they are buttons you can click, drag (Move mode) and right-click.

Right-click a shortcut for Run it, Move mode / Use mode, Remove this shortcut and Remove all my shortcuts. In Move mode, drag shortcuts around; they have a yellow border. Up to 24 shortcuts, saved on your computer (data/kgx_admin_toolbox/atb_hud.json) for every server. A shortcut you cannot use right now (an admin button after you stop being admin, a button hidden from you) is hidden until you can, and greyed out while you hold C. Console: kgxat_atb_hud_toggle switches the mode, kgxat_atb_hud_clear removes them all.

Right-click > ATB

A Treasury Node also offers Open the treasury (v3.6.21.3).

Hold C, right-click a player or entity, and open ATB. The submenu starts with the name of what you clicked.

On a player you get the same list as the Player Manager's right-click menu. It runs from Go to and Bring, through the toggles, Money, Backpack and warnings, to Slay..., Kick..., Ban... and Copy SteamID.

On yourself, Kick..., Ban..., Go to, Bring, Spectate and Warn... are left out. The spawn menu block and blind are offered only to switch them off.

How to use it

Clean up the map from the C menu
  1. Hold C and click the ATB icon.
  2. Open the Server tab.
  3. Click Clean up the map and answer Yes.
Remove a toolbox entity for good
  1. Hold C and right-click the store, container or other toolbox thing.
  2. Open ATB and pick Remove for good (toolbox things with their saved data, permanent and map things).
  3. Answer Yes. Its saved data is deleted too.
Make the window open on the Players tab
  1. Open the ATB window and go to Settings.
  2. Set Open on the tab to Players.
  3. Tick Close this window after a button if you want it out of the way after each click.

Settings and commands

Setting or command What it does Default
kgxat_cmenu Server: 1 = admins get the ATB window and the ATB right-click options 1
kgxat_atb Console: opens the ATB window outside the C menu -

The client options (kgxat_cmenu_props, kgxat_cmenu_tool, kgxat_cmenu_confirm, kgxat_cmenu_close, kgxat_cmenu_tab) are in the window's Settings tab above.

Tips and limits

  • Remove refuses toolbox things such as stores and containers: use Remove for good. Permanent and map things removed with Remove come back after the next cleanup or restart.
  • Open its tool needs a tool gun. Without one you get "You have no tool gun."
  • Every action from the window and the submenu is logged and shown like any other toolbox action.
  • An incognito admin sees the player window, but can still use Leave incognito there.
  • With kgxat_block_contextmenu 1, players whose spawn menu is blocked also lose the C menu. Jailed players always lose it.
  • Hold C also lets you click toolbox windows that stay on screen, such as the Inspector's live info.
