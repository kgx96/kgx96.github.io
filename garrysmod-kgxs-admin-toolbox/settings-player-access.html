Player Access

Pick which toolbox tools and panels non-admin players may use, for all players or for one rank such as VIP.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Player Access lets non-admin players use toolbox tools and panels. You tick an entry for all non-admin players, or for one rank. A player can use something when it is ticked for all players or for their rank.

Admins can always use everything, so admin and superadmin are not in the rank list. Panels are ticked separately from tools, so giving a tool never opens an admin panel.

With rank immunity on (Server Settings), players can never target admins with these tools.

What a tool does for a player (v3.6.11.3)

A tool given to a player is the same tool with restrictions; the orange line under each tool in the panel says which.

  • Building, property and appearance tools work on the player's own things only (their props, doors, NPCs and saved records; a buddy's with the built-in prop protection, or what FPP or another CPPI addon lets them touch). Never on other players' things, the map's own entities, or permanent and server-owned things, whether prop protection is on or off. Options that make server-owned or hidden things (server cameras, keypads, signs, doors...) stay for admins.
  • Player tools (Cheats, Fun, Functions) work on the player themselves. With Players given tools may use the player tools on other players near them ticked (kgxat_grant_others), they also work on other players within the reach set in Settings > Limits ("Reach of player tools on other players", 1000 units), never on anyone ranked above the player.
  • Server setup tools cannot be given to players: Map Gate, Remove Map Props, Mode Spots, Permanent Entities, Property, Spawn Points, the Keys tool, Item Spawner, NPC Spawner, AI Paths, Patrol & Guard (and the superadmin generators and vault). They are greyed out.
  • "Go there" in the tool lists is for admins, and nothing a player does with a tool hands out free money, weapons or items beyond what the gamemode allows. The ticks are saved on the server in data/kgx_admin_toolbox/access.json and apply on every map. By default nothing is ticked.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Player Access.

Only superadmins can change player access. Everyone else sees the checkboxes greyed out, with the line "Only superadmins can change player access." The server also refuses changes from anyone who is not a superadmin. With a server owner set (v3.6.12, kgxat_owner add <SteamID> in the server console), only owners can change player access; see Settings > Permission Report.

The panel

Option What it does
Applies to Which group the ticks below are for: All non-admin players, or Rank: <name> for one rank. Switching it shows that group's ticks.
Refresh rank list Fills Applies to again.
Tool and panel checkboxes One per toolbox tool and per access panel, grouped under headings: Cheats, Fun, Functions, Building, World, Properties, Utilities. Panels end in "(panel)" and are listed under Utilities. Each tick is saved as soon as you click it.

How to use it

Let every player use one tool
  1. Open Q menu > KGX's Admin Toolbox > Settings > Player Access as a superadmin.
  2. Leave Applies to on All non-admin players.
  3. Tick the tool, for example God Mode. It is saved at once.
  4. As a non-admin, God Mode now works; other tools and panels are still refused.
Give a rank extra tools
  1. In Applies to, pick Rank: <name>, for example Rank: vip. If the rank is missing, press Refresh rank list.
  2. Tick the tools and panels that rank should have.
  3. Players of that rank can use them; players of other ranks cannot (unless ticked for all players).
Take everything away from a group
  1. Pick the group in Applies to.
  2. Press Untick everything (for the selection above).

Tips and limits

  • Players given a tool here are "limited players": Settings > Limits applies to them, along with the value caps and the tool cooldown (Server Settings).
  • A tool hidden from a player in Settings > Tool Visibility cannot be used, even when it is ticked here.
  • A license can also give tools: Settings > Licenses (Tool License). Its holders use those tools like a Player Access tick.
  • Allow everything also ticks the tools in the table above. Read the orange lines first.
  • A rank with nothing ticked is removed from the saved file.
  • Reset everything / wipe map data... in Server Settings can untick everything for players and ranks.
