Licenses

Set the license rules (property, guns, driving, jobs), pick the Tool License's tools, and make your own custom licenses.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does
  2. Where to find it

  4. How to use it
  5. Settings and commands

What it does

Licenses are kept with each player's SteamID. Anyone can buy them at a store that sells them; the F3 hub's Server Store has every built-in one. Admins give and take them in the Player Manager (right-click a player > Licenses).

This panel sets which actions need a license: buying property, buying guns and ammo, driving, and taking jobs. It lists the built-in licenses.

It also sets the Tool License: its holders may use the tools you pick, like a Player Access tick. You can make custom licenses too, which can need another license first, be free for some jobs or ranks, and carry their own tools.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Licenses.

Only superadmins can change these settings. Everyone else sees the line "Only superadmins can change these settings." with the controls greyed out. With a server owner set (v3.6.12), only owners change which tools licenses give and the ranks that get them free. Players see their own licenses with the !licenses chat command.

The panel

Rules

Each checkbox applies as soon as you tick it.

Option What it does Default
Buying or renting property needs a Property License Property needs the Property License. On
Buying guns and ammo (stores, shipments) needs a Gun License Weapons and ammo from stores and shipments need the Gun License. Off
Driving a vehicle needs a Driver's License (not seats or chairs) Entering a vehicle needs the Driver's License. Off
Jobs that ask for a license need it (Settings > Jobs: Needs license) Jobs with "Needs license" can only be taken with it. On

Any store item can ask for a license too (Store editor > Items: Needs ...). Jobs can also give their members licenses while they are in the job (Settings > Jobs).

Tool License

A status line shows how many tools it has, and the ranks that get it for free.

Option What it does
Tool License: free for these ranks... Pick ranks that have the Tool License without buying it. Saved when you press Done.
Tool License: pick its tools... Opens a tool browser with search. Tick the tools, then Done saves them.

Tools marked "also: ..." in the browser unlock more than the tool (the same notes as Player Access).

How to use it

Require a Gun License
  1. Open Q menu > KGX's Admin Toolbox > Settings > Licenses as a superadmin.
  2. Tick Buying guns and ammo (stores, shipments) needs a Gun License.
  3. A player without one now sees "You need a Gun License to buy <item>." at stores and shipments.
Hand out tools with the Tool License
  1. Press Tool License: pick its tools....
  2. Search, double-click the tools to tick them, then press Done.
  3. Players who buy the Tool License (or get it in the Player Manager) can use those tools.
  4. To give it to a rank for free, press Tool License: free for these ranks... and pick the rank.
Make a custom license
  1. Type an Id (letters, digits, _), for example fishing, and a Name.
  2. Optional: pick Needs this license first, for example General License.
  3. Optional: fill Free for these jobs (comma separated) or press Free for these ranks....
  4. Press Add / replace (by id) and save.
  5. Sell it with the Store Maker (item type License), or give it in the Player Manager.

Settings and commands

Convar / command Default What it does
kgxat_property_license 1 Property needs a Property License.
kgxat_license_gun 0 Guns and ammo need a Gun License.
kgxat_license_driver 0 Driving needs a Driver's License.
kgxat_license_jobs 1 Jobs that ask for a license need it.
!licenses / kgxat_mylicenses Shows your licenses in chat.
kgxat_licenses [name] Admins: lists every license in the console, and which ones a player has.

For server Lua: KGXAT.RegisterLicense({id = "fishing", name = "Fishing License", desc = "Fish at the pier.", check = function(ply) return true end, onGive = function(ply) end, onTake = function(ply) end}), KGXAT.HasLicense(ply, "fishing"), and the hook KGXATLicenseChanged(ply, id, on). The Logic tool's License action gives or takes one.

Tips and limits

  • Admins are not blocked by the gun and driver rules.
  • The driver rule does not cover seats and chairs.
  • Up to 64 custom licenses. Each can be free for up to 16 jobs and 32 ranks.
  • Licenses free for a rank follow rank changes at once.
  • Saved in data/kgx_admin_toolbox/license_custom.json.
  • A custom license that used the id tool is renamed tool_custom; tool is the built-in Tool License.
  • A tool hidden from a player in Settings > Tool Visibility cannot be used, even with a license.
