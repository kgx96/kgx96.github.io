Permission Report

What every rank can really do with the toolbox, where each grant comes from, warnings for risky grants, and the server owners.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Permission Report lists, for every rank, the tools and panels its players can use, and where each one comes from: Player Access for all players, Player Access for that rank, a Tool License (free for the rank, or when they have it), a job, or a setting that opens a tool to everyone. Toolbox admin ranks show "Every tool and panel".

Notes show what is not really usable: a tool hidden by Tool Visibility, or an old tick on a server setup tool (those cannot be given to players).

The warnings list shows risky grants first: Store Maker, Money Generator, Logic, Money Printer, Test Dummy and Give given to players; Player Manager, Bans, Economy, Server Tools, Maps and Storage panels given to players; staff jobs that give whitelisted players full toolbox access; player tools on other players (kgxat_grant_others); and no server owner set.

It also shows the server owners (v3.6.12). Owners are a level above superadmin.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Permission Report.

Toolbox admins can see it. Everyone else sees "Only admins can see this page." The owners' names and SteamIDs are only sent to superadmins and owners.

The panel

Control What it does
Owners line "No owner set: superadmins do owner things.", or the owners and whether you are one.
Refresh Asks the server for the report again.
Warnings list Level (HIGH, Medium, Info) and the warning, worst first. Hover a row for the full text.
What this rank can do Pick a rank. The list below shows its tools and panels.
Rank list Tool / panel, From (where it comes from) and Note (hidden, blocked). Hover a row for what the tool does when given to a player.
Summary line Licenses that give tools, jobs that give tools or toolbox access, and who counts as a toolbox admin.
Copy the whole report Copies everything (owners, warnings, every rank, licenses, jobs) as text, to paste in a message or a file.

Server owners

With no owner set, superadmins do everything below, as before. With at least one owner set, only owners can:

What Where
Change ranks: make, remove, give, the default rank, auto-ranks, rank presets Functions > Ranks, Player Manager > Give rank, kgxat_rankpreset
Change the auto-rank ladder and hours played Settings > Playtime & Auto-Ranks
Change Player Access (all players and per rank) Settings > Player Access
Change which tools licenses give, and the ranks that get them free Settings > Licenses
Use the scheduler (it runs console commands) Settings > Scheduler
Make, restore, upload and delete backups; reset everything Settings > Backup / Restore, Server Settings
Save logic outputs that run a server console command or Lua World > Logic

Owners are set only from the server console (or rcon), so an admin account cannot make itself owner. An owner who is incognito has no owner powers. An owner can fix ranks in Functions > Ranks even without an admin rank.

How to use it

Set yourself as the owner
  1. Open the server console (or use rcon).
  2. Type kgxat_owner add STEAM_0:1:12345678 with your SteamID, or kgxat_owner add Kris with part of your name while you are online.
  3. Type kgxat_owner list to check. The Permission Report now says you are an owner.
Check what players can do
  1. Open Settings > Permission Report.
  2. Read the warnings first. Each one names the rank, license, job or setting that gives the risky grant.
  3. Pick user in What this rank can do to see what every player has, then your other ranks (VIP and the like).
  4. Change what you do not want in Settings > Player Access, Licenses or Jobs, then press Refresh.
Share the report
  1. Press Copy the whole report.
  2. Paste it where you need it (a staff channel, a file).

Settings and commands

Command Who What it does
kgxat_owner add <SteamID or part of a name> Server console / rcon Makes a player an owner.
kgxat_owner remove <SteamID> Server console / rcon Takes an owner off. With none left, superadmins do owner things again.
kgxat_owner list Server console / rcon Lists the owners.
kgxat_owner clear Server console / rcon Takes every owner off.

Tips and limits

  • Owners are stored in data/kgx_admin_toolbox/owners.json.
  • Whether a rank is a toolbox admin is read from your admin mod's inheritance (CAMI) or the toolbox's ranks; an admin mod that gives the toolbox privilege some other way can differ.
  • Logic nodes saved by a superadmin before owners were set keep their console and Lua outputs until someone without owner powers saves them again (then those outputs are dropped).
  • Server settings (Server Settings, Limits, Tool Visibility, Jobs) stay with superadmins.
