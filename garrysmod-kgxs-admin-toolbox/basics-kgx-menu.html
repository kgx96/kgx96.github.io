KGX Menu

The toolbox's page under Q menu > Utilities > KGX, and with KGX Core 1.3.3 one theme and one translation editor for every KGX addon.

Guide / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel

What it does

v3.6.21.6.1: the toolbox has a page of its own in Q menu > Utilities > KGX, next to KGX Core's pages (KGX Core, KGX Access, KGX Translations). It shows the toolbox's version, what it is, buttons into the toolbox tab, and the main server switches.

With KGX Core 1.3.3 or newer (a required item of the toolbox), two more things are shared with every KGX addon:

  • One theme. The toolbox's eight dark-menu themes are KGX themes. Pick one on the KGX Core page and the spawn menu, KGX windows and KGX screens all use it. The dark-menu rows (Dark menus, brightness, colored text) are on the KGX Core page.
  • One translation editor. The toolbox's phrases are on KGX Translations with every KGX addon's. An edit there wins in the toolbox at once.

Without KGX Core, or with an older Core, the toolbox page still shows, and Settings > Display and Settings > Translations work as before.

Where to find it

Q menu > Utilities > KGX > KGX's Admin Toolbox. Everyone can open it. Only superadmins change the server switches; others see them greyed out.

The panel

Option What it does
Version line KGX's Admin Toolbox v... by KGX PRODUCTIONS, and where its tools are.
KGX Core line Whether the language, theme and translations are shared through KGX Core, that Core needs an update to 1.3.3, or that Core is not installed.
Open the toolbox tab Opens the toolbox tab of the spawn menu (Settings > Server Settings, or the first toolbox page you can see). If the server shows the tab to admins only, it says so.
Setup Wizard The server owner only (superadmins while no owner is set): opens the Setup Wizard.
Read the README and patch notes Opens the in-game README (kgxat_readme).
Translations (KGX Translations) With KGX Core 1.3.3: opens KGX Translations on the toolbox's phrases.
Main server settings

The same settings as Settings > Server Settings (superadmins):

Option Server setting
Superadmins only (admins cannot use the toolbox) kgxat_superadmin_only
Players see the toolbox tab and its weapons (off = admins only) kgxat_atb_menu_players
Show every action to admins in chat kgxat_notify_admins
Write the action log to data/kgx_admin_toolbox/logs/ kgxat_log_file
Admin chat commands (!bring, !goto, !freeze... type !help) kgxat_chat_commands
Block the spawn menu (Q) and spawning for non-admins kgxat_block_spawnmenu
Show the toolbox version and copyright in chat when a player's game loads kgxat_credit_message

Every other server setting is in the toolbox tab > Settings > Server Settings.

How to use it

Pick one theme for every KGX addon
  1. Open Q menu > Utilities > KGX > KGX Core.
  2. In Theme, pick one of the toolbox's themes (Graphite, Slate blue, Ocean teal, Forest green, Royal purple, Crimson, Amber, Midnight). The dark menus turn on if they were off.
  3. Under it, set Dark menus (Off, Spawn menu (Q) and context menu (C), Every game menu and window), Brightness (higher = lighter) and Colored text.
  4. Picking Dark or Light (KGX Core's own) changes KGX windows only; the dark menus keep the last toolbox theme. Changing the toolbox theme elsewhere (the console, a reset) then leaves Dark or Light alone.
Change a toolbox phrase
  1. Open Q menu > Utilities > KGX > KGX Translations (or press Translations (KGX Translations) on the toolbox page).
  2. In Addon, pick KGX's Admin Toolbox; pick the Language.
  3. Double-click a phrase and type the new text. Empty = back to the toolbox's own text.

Tips and limits

  • On the first map start with KGX Core 1.3.3, the toolbox's own phrase edits and languages move to KGX Translations; edits already made there win. A copy stays in data/kgx_admin_toolbox/lang_<code>_moved_to_core.json and lang_custom_moved_to_core.json. A language file put in the toolbox's folder later moves at the next start.
  • Edits KGX Core has no room for (3000 per language) stay in the toolbox's own file and still work.
  • If KGX Core already has 16 languages of the server's own, a toolbox language it cannot take stays with the toolbox: it still works, players pick it in Settings > Display (themes), and the owner edits it under Settings > Translations, below the pointer.
  • Who may change phrases stays the toolbox's rule: the server owner (also one without the superadmin rank), or superadmins while no owner is set. With the toolbox installed this applies to every KGX phrase.
  • A toolbox theme picked before the update is kept and becomes the KGX theme, once (kgxat_core_theme_linked): a Dark picked afterwards stays Dark.
