Keybinds

Set every toolbox key in one place: backpack, third person, cameras, Admin Vision, dark mode and four quick tool keys.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

Keybinds puts every toolbox key in one place: backpack, third person, the Reanimate command wheel, cameras, Admin Vision, dark mode, and the key that opens the tool of what you look at. It also has four quick tool slots: a key that switches straight to a chosen toolbox tool.

These are your own settings, saved only on your computer. Keys do nothing while you type or have a menu open.

Setting a key that something else already uses shows a warning. It checks other toolbox keys, Throw Equipped's throw key and your own console binds.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Keybinds.

Everyone can set their own keys. The Admin Vision key and the look-at-tool key only work for admins. The server option at the bottom is shown to superadmins only.

How to use it

Set a key
  1. Open Q menu > KGX's Admin Toolbox > Settings > Keybinds.
  2. Click the box under the line, for example Third person: tap on/off, hold to look around.
  3. Press the key. If it is used elsewhere, a notice lists what else uses it.
Put a tool on a key
  1. In Quick tool 1, pick a tool, for example Teleport.
  2. Click the box under Key for quick tool 1 (none by default) and press a key.
  3. Press that key in game: the tool gun switches to that tool.
Start over with the recommended keys
  1. Press Use the recommended keys.
  2. Read any clash warnings and change those keys.

Tips and limits

  • Mouse button keys (such as middle mouse) do nothing while the cursor is visible.
  • When keys are given on first join, a chat message says how many were set and where to change them.
  • The look-at-tool key is cleared if it is on G or on Throw Equipped's key, with a chat message. Pick another key (O recommended).
  • Keypads have no key of their own: look at one and type the code on the number pad, or press E.
  • The third person and camera keys can also be set in their own panels.
