Server Settings

The toolbox's main server options: who may use it, immunity, logging, spawn rules, cooldowns, AFK, daily restart, incognito and resets.

What it does

Server Settings holds the toolbox's main server-wide options. Every checkbox and slider here sets a server convar, so the change applies to all players and is kept after a restart.

The top of the panel shows the toolbox version. It also says how admin access works: with an admin mod installed, the toolbox uses the CAMI privilege "KGX Admin Toolbox"; without one, it uses the admin and superadmin ranks. Every action is written to the server console.

It also has the incognito buttons, a scan-and-update button, the ATB item pictures and the full reset window.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Server Settings.

Only superadmins can change these settings. Everyone else sees the controls greyed out, with the line "Only superadmins can change these settings."

Incognito

Scan & update
Option What it does
Scan & update everything (ranks, jobs, warps, world data, logic, sounds, NPCs, licenses, access) Sends every toolbox list again, rebuilds toolbox things from their saved data, and reapplies licenses and access rules. Nothing saved is changed. One notice lists what was updated.

Use it when a rank, job or anything else made with the toolbox does not show up in a list or picker.

How to use it

Change an on/off setting
  1. Open Q menu > KGX's Admin Toolbox > Settings > Server Settings as a superadmin.
  2. Tick or untick the checkbox. It applies at once and is logged as an action.
Schedule a daily map restart
  1. Set Daily map restart: hour, server time (-1 = off) to the hour (server clock), then press its Apply button.
  2. Set Daily map restart: minute, then press its Apply button.
  3. Players are warned 10 and 5 minutes before, then the normal map change countdown runs.
Play as a normal player
  1. Press Go incognito (play as a normal player).
  2. Pick the name and model others see, or keep yours.
  3. To come back, press Leave incognito, type !unincognito, run kgxat_unincognito, or rejoin.
Use your own ATB item pictures
  1. Make a square PNG (128x128 or 512x512) for each item, named after its class, e.g. kgxat_lockpick.png. Use Copy the list of ATB class names for the names.
  2. Put them in an addon folder: garrysmod/addons/my_atb_icons/materials/kgxat_custom/.
  3. On a server, add that folder to the server's Workshop collection, or add resource.AddFile("materials/kgxat_custom/kgxat_lockpick.png") lines in a server Lua file.
  4. Pick Custom in Pictures of ATB weapons and entities. Items without a picture keep the toolbox's.

The reset window

Reset everything / wipe map data... opens a window for the server owner (superadmins when no owner is set). It cannot be undone except by restoring a backup.

  1. Press Make a backup now (it changes to "Backup saved (check Settings > Backup)"). The server also saves a backup automatically right before it resets or wipes.
  2. Tick what to reset: Server settings, limits and caps (every page under Settings), Player Access (untick everything for players and ranks), Paycheck amounts per rank, My tool settings and display options (on this computer). All four start ticked.
  3. v3.6.13.1: pick what saved data to delete under Also delete saved data (for a blank start):

Nothing - keep all saved data Nothing (the default). Only the ticked settings are reset.
This map's world data (map name) On the current map: warps, zones, signs, spawn points, spawners, teleporters, stores, containers, permanent props, map doors, server keypads, buttons and cameras, chairs, logic, sounds, notes, decals, properties, NPC paths and relations, media screens, robbery spots, vault spots and buy stations (v3.6.17). Other maps, money, players' things and bans stay. Picking it unticks the settings ticks.
World data of every map The same, for every map that has toolbox data.
Everything the toolbox saved (like a fresh install) Every toolbox data file: all map data, money and bank, backpacks, vaults, pockets, stats, XP, licenses, mail, jobs, stores, loot tables, prefabs, rules, reports and the rest. Picking it ticks the settings ticks.
  • Keep ranks and staff (ticked; only for Everything): ranks given in the toolbox, staff ranks, the auto-rank ladder and incognito stay. The owner list is always kept.
  • Keep bans, warnings and the join whitelist (ticked; only for Everything).
  • Also delete logs (unticked): action, kill and money logs. Backups never hold logs, so they cannot be restored. 4. Type RESET (or WIPE when something is deleted) in the box, then press Reset to defaults (or Back up, wipe and restart the map).

Without a wipe, never touched: warps, zones, spawn points, teleporters, stores, containers, loot tables, spawners, money, bans, warnings, reports, logs, prefabs, permanent props, rules, favorites and backups.

Settings and commands

Each option's convar is shown in its row above. Commands:

Command What it does
kgxat_incognito / !incognito Go incognito (opens the name and model window).
kgxat_unincognito / !unincognito Leave incognito. From the server console, add a name or SteamID.
kgxat_scanall Scan & update everything (superadmins).

Tips and limits

  • The console ranges of kgxat_warp_cooldown (0-600) and kgxat_warn_kick (0-50) are wider than the sliders.
  • Reset to defaults on the panel does not change the ATB picture setting. The reset window's "Server settings" option resets every toolbox server setting.
  • kgxat_pp and kgxat_pp_world appear in the panel's console list but are set in Utilities > Prop Protection.
  • Superadmin override never applies while you are incognito.
  • Superadmins are never spawn-menu blocked.
