Diagnostics

Find problems with other addons, the server and the toolbox: a compatibility scan, a list of toolbox things on the map, and a player scan.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Diagnostics gives admins three windows for finding problems.

The compatibility scan checks the server and your own game. It finds other admin mods, prop protections and economies, and other addons' hooks that can decide before the toolbox. It also checks the gamemode, edicts, ragdolls, the nav mesh, missing models, broken data files and toolbox Lua errors.

Toolbox things on the map lists everything the toolbox spawned or marks, so you can find it, inspect it or remove it. Players (server user scan) shows every player's rank, connection, what they own, family sharing, jail state and anti-cheat strikes.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Diagnostics.

Toolbox admins only. Players who are not admins only get the "You" part of the compatibility scan; the server parts and the other two windows return nothing.

Console: kgxat_scan prints the scan of your game and, for admins, the server. The server console can run kgxat_scan too.

The panel

Button What it does
Compatibility scan (other addons, server, content, data files) Opens the compatibility scan window.
Toolbox things on the map Opens the list of toolbox things.
Players (server user scan) Opens the player scan window.
Scan for hover previews (spawn menu and lists) Reports what the hover preview can show.

The windows

Compatibility scan

Columns: Level, Where, Result. Levels are OK (green), INFO, WARN (yellow) and BAD (red). WARN means another addon can decide before the toolbox there. BAD needs fixing.

Section What it checks
Server Toolbox version, game branch, map; sandbox-based gamemode (BAD if not); server FPS against the tickrate; edicts out of 8176; entity counts; ragdolls (WARN above 60); nav mesh; the toolbox mounted twice.
Other addons ULX, SAM, ServerGuard, xAdmin, FAdmin, DarkRP, Falco's Prop Protection, Pointshop, Pointshop 2, Wiremod, ACF, a CPPI prop protection, and any net message wrapper.
Hooks of other addons (server) Other addons' hooks on the server events the toolbox uses, with their files.
Models Models in the toolbox lists that are missing (a game not mounted), and the mounted games.
Data files Every data/kgx_admin_toolbox/*.json file; BAD for each one that cannot be read.
Lua errors Toolbox Lua errors this session, if the game reports them.
Your game Game version, branch, resolution, FPS, Lua memory, mounted games, whether the README parts loaded.
Hooks of other addons (your game) Other addons' hooks on client events such as CalcView, with a note when a third person or camera addon may hide the toolbox third person.
Lua errors (your game) Toolbox Lua errors on your game.

Controls: Live (scan again every 3 seconds), Print to console, Scan again. Double-click a row to copy its text.

Toolbox things on the map

Columns: Kind, Class, Model, Owner, Distance, sorted by distance from you. The dropdown filters by kind and shows counts. Refresh reloads the list.

Kinds include Permanent prop, Generated (Generate tools), Trashcan, Chair / seat, Item spawner item, NPC spawner NPC, Reanimated NPC, Mover, Bought vault, Test Dummy, Toolbox entity and Toolbox weapon (dropped).

Right-click a row:

Option What it does
Go there Moves you next to it. Double-click does the same.
Inspect Opens its info window.
Remove it Removes it from the map.
Remove every "(kind)"... Asks to confirm, then removes every thing of that kind.
Players (server user scan)

Updates every 2 seconds. Columns: Player, Rank, Ping, Loss, Min, Props, Owns, NPCs, Ragdolls, Vehicles, Family share, Jailed, Strikes, Last anti-cheat flag. Rows with anti-cheat strikes are red.

Family share means the player plays on a game shared from another account. Ban evaders use this.

Right-click a row:

Option What it does
Copy SteamID Copies the SteamID.
Anti-cheat history Shows the player's last strikes.
Clear anti-cheat strikes Sets their strikes to 0.
Freeze everything (name) owns Freezes what they own.
Remove everything (name) owns... Asks to confirm, then removes what they own.

How to use it

Check a new server or addon setup
  1. Open Utilities > Diagnostics and press Compatibility scan (other addons, server, content, data files).
  2. Read the BAD rows first, then WARN.
  3. For a WARN hook row, the file shown is the other addon that can decide before the toolbox.
  4. Press Print to console to keep a copy.
Watch the server under load
  1. Open the compatibility scan and tick Live (scan again every 3 seconds).
  2. Watch server FPS, edicts and entity counts change as players build.
Clean up toolbox things
  1. Press Toolbox things on the map.
  2. Pick a kind in the dropdown, for example Trashcan.
  3. Right-click a row > Go there to look at it, or Remove every "Trashcan"... to clear them.
Look into a suspicious player
  1. Press Players (server user scan).
  2. Check Family share, Strikes and Last anti-cheat flag.
  3. Right-click > Anti-cheat history, or freeze or remove what they own.

Settings and commands

Command What it does
kgxat_scan Client: prints your game's scan, plus the server part for admins. Server console: prints the server scan.

Tips and limits

  • Removing a thing only takes it off the map now. Permanent things come back after a restart.
  • Remove every "(kind)"... never removes Test Dummies, since they are players.
  • The toolbox things list shows at most 3000 rows.
  • A broken data file can be restored from Settings > Backup / Restore.
  • With another CPPI prop protection installed, the toolbox's own prop protection stays off.
  • Wallhacks and other client-only cheats cannot be seen from the server. See Settings > Anti-Cheat for the checks that exist.
