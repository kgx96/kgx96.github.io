Admin Notes

Keep private staff notes about players by SteamID, also for players who left, and see them when that player joins.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Admin Notes keeps private notes about players, stored by SteamID. Notes stay after the player leaves, so you can build a record across visits.

When a player with notes joins, admins with access get a chat line with the number of notes and the latest one. Only admins and players given access can read notes.

This panel is not the World > Notes tool, which places notes in the world.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Admin Notes.

Toolbox admins can use it. Players can get it through Settings > Player Access with the Admin Notes tick. Without access, the panel says "Only admins (or players given access) can read admin notes."

Other ways in:

  • Player Manager: right-click a player > Admin notes....
  • Reports: right-click a report > Admin notes of the reporter....
  • Damage Log: right-click a line > Admin notes of the attacker....

The panel

Item What it does
Filter by name or SteamID... Shows only players whose name or SteamID contains this text.
Player list Columns Player (name and SteamID), Notes (count) and Last (date of the latest note), newest first.
Double-click a player Opens their notes window.
SteamID box A SteamID like STEAM_0:1:12345, for someone not online.
Open notes for this SteamID Opens the notes window for that SteamID.
Refresh Reloads the list.
The notes window
Item What it does
Note list Columns When, By and Note.
Double-click a note Shows the full text.
Right-click > Copy Copies the note text.
Right-click > Delete note Deletes the note at once, without asking.
Text box at the bottom Type a note and press Enter to save it.

How to use it

Note a player's behavior
  1. Open Player Manager and right-click the player.
  2. Pick Admin notes....
  3. Type the note, for example "Warned for prop spam, was cooperative", and press Enter.
Look up a player who left
  1. Open Utilities > Admin Notes.
  2. Type part of their name or SteamID in the filter box.
  3. Double-click the player to read their notes.
Add a note for an offline SteamID
  1. Paste the SteamID into the SteamID box.
  2. Press Open notes for this SteamID.
  3. Type the note and press Enter.

Tips and limits

  • A note can be up to 500 characters. Line breaks become spaces.
  • Each player keeps at most 100 notes. Adding more removes the oldest.
  • A player's name is updated when they join or when a note is added while they are online.
  • Notes are saved in data/kgx_admin_toolbox/notes.json for every map.
  • Adding a note is written to the server log, not to the Action Log.
  • The SteamID box only accepts the STEAM_X:Y:Z form.
