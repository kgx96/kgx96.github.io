Maps

Search the maps installed on the server and change or restart the map after a countdown that warns every player.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Maps lists every map installed on the server and lets you change to one of them, or restart the current map. Each change runs after a countdown you choose.

Everyone gets a chat line and an on-screen notice when the countdown starts, and again 10 seconds before the change. You can cancel the change at any time before it happens.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Maps.

Admins, or players ticked for Maps (change / restart map) in Player Access.

The panel

Option What it does Default Range
Status line Current map, the map it is Changing to (if any) and how many maps are installed.
Search box Filters the list by name as you type.
Map list Every installed map. The current one is marked "(current)". Double-click a map to change to it.
Countdown (s) Seconds before the change or restart. 0 changes at once. 10 0-120
Change to selected map Asks to confirm, then starts the countdown to the selected map.
Restart current map Asks to confirm, then starts the countdown to reload the current map.
Cancel map change Stops a pending change and tells everyone it was cancelled.
Rescan installed maps Reads the server's map list again, for example after adding a map.

How to use it

Change the map with a warning
  1. Open Utilities > Maps.
  2. Type part of the map name in the search box.
  3. Select the map and set Countdown (s), for example 60.
  4. Click Change to selected map and confirm with Change.
  5. Everyone is told now and 10 seconds before the change.
Restart the current map
  1. Set Countdown (s).
  2. Click Restart current map and confirm with Restart.
Stop a change
  1. Click Cancel map change before the countdown ends.

Tips and limits

  • Only maps found in the server's maps folder (.bsp files) are listed and accepted. Anything else gives "That map is not installed on the server."
  • The map list is read once and kept. Click Rescan installed maps after you install new maps.
  • Starting a new change replaces a pending one.
  • With a countdown of 10 seconds or less there is no second "in 10 seconds" warning. With 0 seconds there is no warning at all.
  • Changes, restarts and cancels are written to the Action Log.
