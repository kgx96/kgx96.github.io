Discord Logs

Post toolbox logs (bans, kicks, warnings, jails, reports and more) to a Discord channel through a webhook.

What it does

Discord Logs posts toolbox log lines to a Discord channel through a webhook. You pick which kinds of events are posted: bans, kicks, warnings, jails, player reports, other admin actions, joins and leaves, and server events.

Lines are collected and posted together every 3 seconds, in one message per batch. Each message is a code block, so names and reasons cannot ping anyone or change the formatting.

The webhook link is kept on the server and never shown again in full.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Discord Logs.

Superadmins only. Other players see the description and "Only superadmins can set this up."

Each checkbox is saved as soon as you tick it.

How to use it

Connect a Discord channel
  1. In Discord, open the channel settings > Integrations > Webhooks > New webhook > Copy webhook URL.
  2. In game, open Settings > Discord Logs and paste the link into the field.
  3. Press Save the webhook link. Webhook: now shows the short form and Posting on is ticked.
  4. Press Send a test message. "Test sent (HTTP ...). Check the channel." means it works.
Choose what gets posted
  1. Tick the kinds of events under Post.
  2. Tick All other admin actions only if you want every toolbox action in the channel.
  3. Trigger something, for example warn a bot. It shows in the channel a few seconds later.
Pause or remove it
  1. Untick Posting on to pause. The link stays saved.
  2. Press Remove the webhook and confirm to stop and forget the link.

Settings and commands

File What it holds
garrysmod/data/kgx_admin_toolbox/discord.json The webhook link, name, on or off, and the categories.

Tips and limits

  • Only links on discord.com, discordapp.com, ptb.discord.com and canary.discord.com are accepted, starting with https://.
  • Admin actions are sorted by their text: lines with "banned" go to bans, "kicked" to kicks, "warned" or "warning" to warnings, "jail" to jails. Everything else counts as other admin actions.
  • Anti-cheat strikes are admin actions, so they follow the same sorting.
  • At most 200 lines wait in the queue. Lines beyond that are dropped until the queue empties.
  • A Discord message holds about 1900 characters of log lines. Longer batches are split over the next posts.
  • Mentions such as @everyone in names or reasons are never pinged.
