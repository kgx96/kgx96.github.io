Movement

Change walk speed, run speed, jump power and gravity.

Tool / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Movement sets four values on a player at once: walk speed, run speed, jump power and gravity. Gravity is a multiplier: 1 is normal, 0.5 is half.

The first time you change a player, the tool remembers their original values. Reload puts those originals back. The change also ends when the player respawns.

Where to find it

Q menu > KGX's Admin Toolbox > Cheats > Movement.

Toolbox admins can use it. With a CAMI admin mod (ULX, SAM, sAdmin) that means the KGX Admin Toolbox privilege, default rank admin. Without one, admin and superadmin can use it. A superadmin can give it to non-admin players, or to one rank, in Settings > Player Access.

Given to a player (v3.6.11.3): Themselves (gravity 0.5 to 2, speed and jump caps).

Controls

Key What it does
Left click Apply to the player you aim at
Right click Apply to yourself
Reload Reset the player you aim at (or yourself)

The panel

The panel lists the Sandbox defaults: walk 200, run 400, jump 200, gravity 1.

Option What it does Default Range
Walk speed Normal walking speed. 200 1-10000
Run speed Speed while sprinting. 400 1-10000
Jump power How high the player jumps. 0 = no jumping. 200 0-10000
Gravity multiplier How strongly gravity pulls the player. 1 0.05-10
Reset to defaults Puts the sliders back to the defaults above.

How to use it

Make a player fast and floaty
  1. Set Run speed to 1000, Jump power to 400 and Gravity multiplier to 0.3.
  2. Aim at the player and left-click. All four values are applied together.
  3. Your notice shows the values that were set.
Slow a player down
  1. Set Walk speed and Run speed to 100, and Jump power to 0.
  2. Aim at the player and left-click.
Undo it
  1. Aim at the player and press reload. Aim at nothing to reset yourself.
  2. Their original walk, run, jump and gravity come back.
  3. If they have no changes, you get "... has no movement changes to reset."

Settings and commands

Setting What it does Default Range
kgxat_cap_speed Most walk and run speed a limited player's tool may set. Settings > Limits, Walk / run speed. 800 0-10000
kgxat_cap_jump_power Most jump power a limited player's tool may set at normal gravity. With lower gravity the cap is lowered so the jump is never higher (v3.6.11.3). Settings > Limits, Jump power and self-launch. 300 0-10000
kgxat_limits_admins Caps also apply to toolbox admins. Superadmins are never capped. 0 0-1

Tips and limits

  • All four sliders are applied on every click. Set the ones you do not want to change to the player's current values.
  • Respawning clears the change. The gamemode resets speeds, and the toolbox puts the original gravity back.
  • The cap does not limit gravity.
  • Works on players only. Rank immunity applies.
