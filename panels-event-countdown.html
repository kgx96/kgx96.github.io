Event Countdown

Show a big countdown timer with your own title at the top of every player's screen, for events, restarts or rounds.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Event Countdown puts a timer at the top of every player's screen, for example "Event starts in 4:59". You choose the title and the time.

The timer turns red in the last 10 seconds and beeps once a second in the last 5. When it reaches zero it shows "<title> - NOW!" for a few seconds, then disappears. Players who join while it runs see the running countdown.

The countdown is only a display. It does not start or change anything by itself.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Event Countdown.

Admins, or players ticked for Event Countdown in Player Access.

The panel

Option What it does Default Range
Title The text shown before the time. Up to 60 characters. Empty uses "Event starts in". Event starts in
Minutes Minutes on the timer. 5 0-120
Seconds Seconds on the timer. 0 0-59
Start countdown Starts the countdown for everyone. Replaces a running one.
Stop countdown Removes the countdown from every screen.
Reset to defaults (Event starts in, 5:00) Puts the title and time back to the defaults in the panel. It does not stop a running countdown.

How to use it

Announce an event in 10 minutes
  1. Open Utilities > Event Countdown.
  2. Type a title, for example "Boss fight in".
  3. Set Minutes to 10 and Seconds to 0.
  4. Click Start countdown. Everyone sees the timer at the top of their screen.
Cancel it
  1. Open the panel.
  2. Click Stop countdown.

Tips and limits

  • Only one countdown runs at a time. Starting a new one replaces the old one.
  • The shortest countdown is 1 second. The longest the sliders allow is 120:59.
  • Starting and stopping a countdown is written to the Action Log.
  • To actually change or restart the map on a timer, use Utilities > Maps; it has its own countdown.
  • The countdown is not saved; it is gone after a map change.
