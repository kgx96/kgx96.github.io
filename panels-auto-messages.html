Auto Messages

Post your own chat messages one after another every few minutes, such as rules reminders, a Discord link or tips.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Auto Messages posts a list of chat messages in turn, one every few minutes. Each message appears in everyone's chat with a blue "[Server]" tag in front.

The messages go out in the order of the list. After the last one the list starts again at the top. The list, the interval and the on/off state are saved on the server and survive restarts.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Auto Messages.

Admins, or players ticked for Auto Messages in Player Access.

The panel

Option What it does Default Range
Auto messages on Starts or stops posting. Off
Every (minutes) Time between two messages. 5 1-120
Apply interval Saves the interval and restarts the timer.
Message list Columns # and Message, in posting order.
New message Text box for a new message, up to 250 characters.
Add message Adds the text to the end of the list.
Remove selected Removes the selected message.
Send next message now Posts the next message in the list at once.
Reset to defaults (off, every 5 min) Turns auto messages off and sets the interval to 5 minutes. The messages stay.

How to use it

Set up rotating reminders
  1. Open Utilities > Auto Messages.
  2. Type a message in the text box, for example "Please read the server rules."
  3. Click Add message. Repeat for each message.
  4. Set Every (minutes) and click Apply interval.
  5. Tick Auto messages on.
Check how a message looks
  1. Click Send next message now. It appears in everyone's chat at once.
Remove a message
  1. Select it in the list.
  2. Click Remove selected.

Tips and limits

  • At most 50 messages.
  • Nothing is posted while the list is empty, even with auto messages on.
  • Changing the list, the interval or the on/off state restarts the timer, so the next message comes one full interval later.
  • Send next message now does not reset the timer.
  • After a server restart the rotation starts again at message 1.
  • Messages are saved in data/kgx_admin_toolbox/automessages.json.
  • Adding, removing, the interval and turning it on or off are written to the Action Log.
