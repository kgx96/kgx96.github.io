HUD & Hub

Set up the toolbox HUD, the header bar, look-at details and the F3 server hub, with text tokens and presets.

What it does

HUD & Hub controls what players see on screen and in the F3 server hub. The toolbox HUD replaces the game's health, armor and ammo with a card at the bottom left and ammo at the bottom right. You can add up to 3 custom values to the card, a header bar at the top of the screen, and details shown when you look at a player.

The server hub opens with F3 or !hub. It has up to 12 tabs, from the scoreboard to an Admin tab. You set its title, color, tabs, store, key list, help text and links here.

Texts use tokens such as {name} or {wallet}, filled in for each player. The settings are saved for every map. Presets save a whole setup by name and load it on any map.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > HUD & Hub.

  • Only superadmins can change these settings. Others see the first options greyed out and "Only superadmins can change these settings."
  • Players open the hub with F3, !hub or kgxat_hub [tab].

Built-in presets (v3.6.15)

For arena servers (Game Modes with a hub). Loading one also sets Toolbox HUD to Always.

Preset What it sets
[Built-in] PVP (arena) Title Arena, gold accent. Hides Jobs, Server store, Shipments and Mail. Card: Level {level}, Loadout {loadout}, Credits {credits}. Header on: {servername}, {match}, {next}. Key binds and Help for the hub, matches, loadouts and progress. Look-at: name, level and badge.
[Built-in] PVE (waves) Title Survival, green accent. The same tabs and header. Card: Points {matchmoney}, Level, Loadout. Help for survival matches with points.

Text tokens

Use these in the custom values, the header and the look-at lines. In look-at lines they describe the player you aim at.

{job} The player's job (RP: the job or Unemployed; DarkRP and other gamemodes: their team). v3.6.17: on arena servers (a hub, Next match on, or a match running) PVP player or PVE player (the match running or played last); Build / PvP servers: Builder or PvP; else Player. {wallet} Wallet money. Only for yourself; "?" for others.
{bank} Bank money. Only for yourself; "?" for others.
{playtime} Time played.
{kills} Kills.
{deaths} Deaths.
{ping} Ping.
{steamid} SteamID.
{players} Human players online.
{maxplayers} Player slots.
{servername} Server name.
{map} Map name.
{time} Local time, HH:MM.
{date} Date, YYYY-MM-DD.
{mode} Server mode: Sandbox, Build / PvP or RP.
{level} v3.6.15: Match stats level (1 and up).
{loadout} v3.6.15: the loadout the player spawned with, or "-".
{matchmoney} v3.6.15: match money (buy menu, paid loadouts; points in survival modes).

An unknown token is shown as typed.

How to use it

Add a header bar
  1. Open Settings > HUD & Hub and tick Show the header.
  2. Press Header preset: RP, or type your own Left, Middle and Right texts with tokens.
  3. Press SAVE HUD & HUB.
Customize the hub
  1. Change Hub title and pick an accent color.
  2. Untick tabs you do not use. Type a new name under a tab to rename it.
  3. Edit Help & tips with # lines as section titles, and Links as Title | https://....
  4. Press SAVE HUD & HUB, then Open the hub to check it.
Keep a setup for another map or event
  1. Save your settings with SAVE HUD & HUB.
  2. Type a Preset name and press Save the saved settings as this preset.
  3. Later, right-click the preset > Load (replaces the current settings).

Settings and commands

Setting or command What it does Default
kgxat_hud Server: 0 = off, 1 = in RP mode, 2 = always. 2
kgxat_hud_model Server: 1 = live character model on the card. 1
kgxat_look_details Server: 1 = look-at details. 1
kgxat_hub Server: 1 = F3 and !hub open the hub. 1
kgxat_hub_admin Server: 1 = Admin tab for toolbox admins. 1
kgxat_version_text Server: 1 = the version line at the bottom right. 1
kgxat_server_version Server: the server version in that line (empty = Garry's Mod version). Empty
kgxat_version_text_show Each player: 1 = show the version line. 1
kgxat_hud_enable Client: 0 hides the toolbox HUD for yourself. 1
kgxat_hub [tab] Opens the hub. Tabs: scoreboard, players, jobs, stats, store, keys, help, links, admin. -
!hub Chat: opens the hub. -
kgxat_hud_debug Prints why the toolbox HUD draws or not. -

Tips and limits

  • Settings are saved in garrysmod/data/kgx_admin_toolbox/hub.json, presets in hub_presets.json. At most 32 presets.
  • Some tabs also need their feature: Jobs needs toolbox jobs, Server store needs the economy, Mail needs mail on, and Shipments needs shipments and a seller.
  • The Key binds tab also lists each player's own toolbox keys from Settings > Keybinds.
  • Links only become buttons when they start with http:// or https://.
  • Look-at details show within 300 units. Cloaked players are hidden from non-admins.
  • Pressing F3 again closes the hub.
