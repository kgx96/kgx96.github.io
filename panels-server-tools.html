Server Tools

One-click map-wide actions: clean up the map, freeze props, remove NPCs, bring or freeze all players, lock the server, and set time scale and gravity.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Tips and limits

What it does

Server Tools holds actions that affect the whole map or every player at once. Each button runs one action, and the riskier ones ask you to confirm first.

The World section changes the server's time scale (slow motion) and gravity. Every action is written to the Action Log like the tools.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Server Tools.

Toolbox admins can use it. Players can get it through Settings > Player Access with the Server Tools (incl. time scale / gravity) tick.

Most of these actions are also buttons in the C menu's ATB window, for toolbox admins while kgxat_cmenu is on. They use the same Server Tools permission.

The panel

Unfreeze all players Unfreezes every other player. No
Respawn dead players Respawns every dead player. No

Below the buttons a status line shows Server: LOCKED (only admins can join) or Server: open.

World
Option What it does Default Range
Time scale Game speed. 0.5 = half speed (slow motion). 1 0.1-3

Moving a slider does nothing on its own. Press the matching Apply button.

How to use it

Stop a prop lag spike
  1. Open Utilities > Server Tools.
  2. Press Freeze all props. Every physics object stops at once.
  3. The Action Log shows how many objects were frozen.
Gather everyone for an event
  1. Stand where players should gather.
  2. Press Bring all players to me and confirm with Yes.
  3. Press Freeze all players if they should stay still. Press Unfreeze all players to let them go.
Close the server for maintenance
  1. Press Lock / unlock the server (only admins can join) and confirm.
  2. The status line reads Server: LOCKED (only admins can join).
  3. Non-admins who join are disconnected with "The server is locked right now. Please try again later."
  4. Press the button again to unlock.
Slow motion
  1. Set Time scale to 0.5.
  2. Press Apply time scale.
  3. Press Reset time scale to default (1) to return to normal speed.

Tips and limits

  • Bring, freeze and unfreeze all players skip players you cannot target because of rank immunity. They never affect you.
  • Bring all players to me skips dead players.
  • The lock check runs a few seconds after a player joins, once the admin mod has set their rank. Players already on the server stay.
  • Time scale and gravity last until the map changes or you reset them.
  • Clean up map removes everything players built. There is no undo.
  • Server actions have a 1 second cooldown per admin.
