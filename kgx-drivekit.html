02 / About the project

Made for
full drives.

KGX DriveKit

Shows what fills each drive, folder by folder, and frees space without breaking anything: every delete, cleanup and move is checked and explained first, links are never followed, and every move can be undone. Everything runs on your own PC; nothing is sent anywhere.

KGX DriveKit is a free download; its source code is not published. Created by KGX (KGX PRODUCTIONS).

View it on GitHub

Getting started

Download KGXDriveKitSetup.exe from GitHub and run it: it installs to C:\Program Files\KGXtools\KGX DriveKit or any folder you pick, with an updater and an uninstaller. Or download KGXDriveKit.exe on its own and run it from any folder. Windows 10 or 11, 64-bit.
