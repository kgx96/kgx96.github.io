Shipments

Set up shipments that store-owner jobs buy in the F3 hub and resell, plus the store types that decide which job sells what.

Panel / Covers v3.6.21.6.1 / Updated Oct 28, 2026

What it does

Shipments let jobs run their own shops. A job buys a shipment in the F3 hub (Shipments tab). It is a box holding several of one item, placed in front of the buyer. The owner sets the price of one, and everyone else buys one with E. The money goes to the owner.

This page has the shipment rules, the shipment catalog (what can be bought, how many, for how much) and the store types. A store type is a set of classes, such as weapons or food. A job sells the store types ticked for it in Settings > Jobs.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Shipments.

Only superadmins can change these settings. The catalog and store type editors are shown only to superadmins. Others see "Only superadmins can change the shipment list."

The panel

Checkboxes and Owners pay for shipments from take effect at once. The two sliders take effect when you click Apply. Catalog and store type changes are saved straight away, for every map.

Store types (superadmins)

The list shows Store type and Sells. Six come by default: General store, Gun store, Food store, Hardware store, Pharmacy and Black market.

How to use it

Add a pistol shipment for a gun store job
  1. Set Item type to Weapon and Class to weapon_pistol. Type a Name.
  2. Set Units in one shipment and Shipment price (admin set).
  3. Click Add as a new shipment.
  4. In Settings > Jobs, tick Gun store (or General store) for the job.
Sell food
  1. Set Item type to Prop and put a food prop model in Class.
  2. Set Food: health it gives when eaten above 0.
  3. Click Add as a new shipment. It is sold by store types with the Food class.
Run a shipment as an owner
  1. Buy it in the F3 hub, Shipments tab.
  2. Press Alt + E on it for its window.
  3. Pick how it works: Closed shipment, Dedicated box (free) or Store. Use Set the price of one... to set your price.

Tips and limits

  • Shipments need the economy on.
  • The catalog and store types are saved in data/kgx_admin_toolbox/shipments.json, for every map.
  • Owners take their shipments with them when they leave, except shipments set as a store when Shipments set as a store stay... is on.
  • In Store mode, each sale is mailed to the owner's bank. Only stores can be frozen with the physgun.
  • A broken shipment spills everything on the ground for free.
  • The owner's window also has Take one for myself, Unpack: everything falls out on the ground and Throw the shipment away.
  • Jobs made before v3.5.20 without store type ticks: Store owner sells General store, Black market dealer sells Black market.
