Backup / Restore

Save every toolbox setting and data file in one backup, restore it later, and move backups between servers.

Panel / Covers v3.6.21.6.1 / Updated Oct 27, 2026

On this page

  1. What it does
  2. Where to find it
  3. The panel
  4. How to use it
  5. Settings and commands
  6. Tips and limits

What it does

Backup / Restore saves the whole toolbox state in one file. A backup holds every toolbox data file and every toolbox server setting: Player Access, limits, loadouts, warps, zones, signs, spawn points, teleporters, permanent props, prefabs, rules, bans and the rest.

Restoring a backup first saves the current state as a new backup. Then it writes the backup's files and settings and restarts the map after 10 seconds. You can also rename, download, upload and delete backups, so you can share one with another server.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Backup / Restore.

Superadmins only. Other players see the description and "Only superadmins can make or restore backups." With a server owner set (v3.6.12, kgxat_owner add <SteamID> in the server console), only owners can; see Settings > Permission Report.

The Reset everything / wipe map data window in Settings > Server Settings also has a Make a backup now button, and saves a backup automatically before it resets or wipes. To undo a wipe, restore that backup here.

The panel

The list shows every backup on the server, newest first.

Column What it shows
Backup The file name, e.g. backup_2026-10-21_14-30-00.json.
Size Size in KB.
Made Date and time of the file.
Button What it does
Make a backup now Saves a new backup and tells you its path.
Restore selected (restarts the map)... Asks to confirm, saves the current state as a new backup, restores the selected one, then restarts the map in 10 seconds.
Delete selected... Asks to confirm, then deletes the selected backup.
Rename selected... Asks for a new name: 1-60 letters, digits, _ or -. Refused if that name exists.
Copy the selected backup's path Copies garrysmod/data/kgx_admin_toolbox/backups/<name> to your clipboard.
Download selected to my computer Sends the backup to your game. It is saved in your own garrysmod/data/kgx_admin_toolbox_backups/ as a .txt file, and the path is copied.
Upload a backup from my computer... Opens a window listing the .txt and .json files in your garrysmod/data/kgx_admin_toolbox_backups/. Pick one and press Upload the selected file to the server.
Refresh Reloads the list.

How to use it

Make a backup before a big change
  1. Open Settings > Backup / Restore.
  2. Press Make a backup now. The new file appears at the top of the list.
  3. Optional: select it, press Rename selected... and give it a clear name such as before_event.
Restore a backup
  1. Select the backup in the list.
  2. Press Restore selected (restarts the map)... and confirm with Restore.
  3. The current state is saved as a new backup first. Then the backup's files and settings are written.
  4. The map restarts after 10 seconds and everything loads from the restored files.
Copy a backup to another server
  1. On the first server, select the backup and press Download selected to my computer.
  2. The file is saved as garrysmod/data/kgx_admin_toolbox_backups/<name>.txt on your computer. Send that file to the other admin if needed.
  3. The admin who uploads must have the file in their own garrysmod/data/kgx_admin_toolbox_backups/ folder.
  4. On the other server, press Upload a backup from my computer..., select the file and press Upload the selected file to the server.
  5. It is checked and saved as uploaded_<name>.json. Select it in the list and restore it.

Settings and commands

File or folder What it holds
garrysmod/data/kgx_admin_toolbox/backups/ Backups on the server.
garrysmod/data/kgx_admin_toolbox_backups/ Downloads and uploads on your own computer.

Tips and limits

  • Restore also removes toolbox data files made after the backup, with their _tmp and _bak copies. They are kept in the safety backup made first.
  • After a restore the toolbox saves none of its data files until the map changes, so data in memory cannot overwrite the restored files. Logs and backups still save. The console lists each file it held back.
  • Backups leave out the logs, backups, _tmp, _bak and _broken folders.
  • Only toolbox settings stored in the backup are restored. Settings of other addons are not touched.
  • An upload that is not a toolbox backup is refused with "That file is not a toolbox backup."
  • Uploaded names get a number added if the name is taken (uploaded_<name>_2.json).
  • Very large backups cannot be downloaded in game. Copy them from the server's data folder instead.
  • The game cannot open folders. Paste a copied path into your file browser.
  • Moving everything by hand also works: copy a backup file into the other server's garrysmod/data/kgx_admin_toolbox/backups/ folder.
