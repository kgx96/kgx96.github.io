Playtime & Auto-Ranks

Count every player's playtime, promote players to ranks after a number of hours, and see the 100 most-played players.

Panel / Covers v3.6.21.6 / Updated Oct 26, 2026

What it does

The toolbox counts playtime for every player. Players check theirs with !playtime. Auto-ranks promote a player to a rank when they reach a number of hours played.

You build a ladder of steps: after N hours, rank X. Players only ever move up the ladder, never down. Admins, and players with a rank that is not on the ladder (other than user), are left alone.

The panel also lists the 100 players with the most playtime. Superadmins can set a player's hours by hand.

Where to find it

Q menu > KGX's Admin Toolbox > Settings > Playtime & Auto-Ranks.

Admins can see this page; everyone else sees "Only admins can see this page." Only superadmins can change the settings, the ladder and playtime. With a server owner set (v3.6.12), only owners change the ladder and playtime; see Settings > Permission Report. Players use !playtime in chat.

How to use it

Promote players after 10 hours
  1. Make the rank first with Functions > Ranks, for example vip.
  2. Open Q menu > KGX's Admin Toolbox > Settings > Playtime & Auto-Ranks as a superadmin.
  3. Set After hours played to 10 and pick vip in Rank (make ranks with Functions > Ranks). Press Scan ranks (admin mod, toolbox ranks) if it is missing.
  4. Press Add / replace this step.
  5. Online players with 10 hours or more are promoted when you save; others when they reach it. They see "You played <hours> hours and are now <rank>!"
Build a ladder
  1. Add one step per rank, each with more hours: for example 5 h regular, 50 h vip, 200 h veteran.
  2. A player gets the highest step they have reached, and only moves up.
Correct a player's playtime
  1. Find the player in Most played (top 100).
  2. Right-click > Set hours played... and type the hours.
  3. If they are online, their promotion is checked at once.

Settings and commands

Convar / command Default What it does
kgxat_autoranks 1 1 = promote by playtime.
kgxat_playtime_afk 0 1 = AFK time counts as playtime.
!playtime [name] Shows your playtime (or another player's) and your next auto-rank.
kgxat_scanranks Admins: scans every rank and sends the list to every player's rank pickers.

Tips and limits

  • Playtime goes up by one minute every minute for each player online. AFK players count only with kgxat_playtime_afk on.
  • Players start the ladder from user or from the citizen rank. A player whose rank is not on the ladder is never promoted.
  • Admins, incognito players and staff ranks are never promoted by playtime.
  • Ranks are set through ULX or SAM. Without an admin mod, the toolbox sets ranks itself and keeps them in ownranks.json. Other admin mods are not supported for auto-ranks.
  • If a rank cannot be set, the server log says so once; check that the rank exists.
  • When the rank has a chat tag (Settings > Chat Tags & Titles), the promotion message uses the tag's text.
  • Data files: playtime.json (saved every 5 minutes and at shutdown) and ranks.json in data/kgx_admin_toolbox/.
