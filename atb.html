02 / About the project

Garry’s Mod.

KGX's Admin Toolbox

A Garry's Mod admin tool set by KGX PRODUCTIONS. Player Manager, roleplay (jobs, property, police, Mayor), economy (banks, stores, taxes, treasury), game modes, logic, NPCs, translations and more, with Player Access to hand any tool to any rank.

View the addon on Steam

Getting started

Open the Steam Workshop page and select Subscribe. Steam downloads the toolbox and KGX Core (a required item) before you launch Garry's Mod. The toolbox has its own Q menu tab; the full help is on the toolbox website.
