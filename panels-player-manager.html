Player Manager

A live list of every player with a right-click menu of all toolbox actions: teleport, freeze, jail, gag, warn, kick, ban and more.

What it does

Player Manager lists every player on the server with their rank, health and status. Right-click a player to open a menu of everything the toolbox can do to them. Double-click a player to go to them.

Every action goes through the same rank immunity check as the tools. Every action is written to the Action Log and to the player's history.

Where to find it

Q menu > KGX's Admin Toolbox > Utilities > Player Manager.

Toolbox admins can use it. Players can get it through Settings > Player Access with the Player Manager tick.

The same menu is in two other places:

  • C menu: right-click a player, then ATB. Toolbox admins only, while kgxat_cmenu is on.
  • The F3 hub: the Admin tab lists players. Clicking one opens the same actions as a window of buttons. Toolbox admins only, while kgxat_hub_admin is on.

Jailing

Toggle jail uses the jail time from kgxat_jail_minutes (default 0 = until released). With kgxat_jail_ask on (default), a small menu asks where to jail them first. Jail at skips that menu and uses the place you pick.

You may jail yourself. The panel asks first. Get out with !unjailme in chat or kgxat_unjailme in the console.

How to use it

Deal with a rule breaker
  1. Open Utilities > Player Manager.
  2. Right-click the player and pick Go to or Spectate to see what is happening.
  3. Pick Warn..., type the reason and press Warn.
  4. If it continues, use Toggle gag (chat), Toggle jail or Kick....
Ban a player for one day
  1. Right-click the player and pick Ban....
  2. Type 1440 and press Next.
  3. Type the reason and press Ban. They are kicked and the ban appears in Utilities > Bans.
Check a player's record
  1. Right-click the player.
  2. Pick View warnings for warnings only, or View history (everything done to them) for every action.
  3. Type jail, ban or warn in the history filter box to narrow it down.

Settings and commands

Setting or command Default What it does
kgxat_immunity 1 Admins cannot target superadmins, and players are not targeted above their rank.
kgxat_immunity_same 1 Players of the same rank may target each other.
kgxat_jail_minutes 0 Jail time for Player Manager and !jail (0-1440 minutes, 0 = until released).
kgxat_jail_ask 1 Pick the jail location in a menu when jailing.
kgxat_warn_kick 0 Kick at this many warnings (0-50, 0 = off).
kgxat_chat_commands 1 Chat commands with the same actions. Type !help for the list.
kgxat_unblockme Console. A toolbox admin removes spawn menu block, blind, gag, mute and freeze from themselves.
kgxat_unblock <name> Server console or superadmin. Same, for another player, and releases jail.

Tips and limits

  • These options are hidden on your own name: Go to, Bring, Spectate, Warn..., Kick... and Ban.... Toggle spawn menu block and Toggle blind are hidden on yourself unless already on.
  • If the target outranks you, you get "You cannot target (name) (higher rank)."
  • Gag and mute are remembered by SteamID, so rejoining, a map change or a restart does not clear them (saved in restrictions.json). The longest timed gag or mute is 10080 minutes.
  • Gagged players can still use !rules, !report, !warps and a few other commands.
  • The longest timed ban is 525600 minutes. Bots cannot be banned; use Kick....
  • Give Admin Keys only works on toolbox admins.
  • Warnings also run the steps of Settings > Warning Ladder.
  • History keeps the last 100 entries per player across visits.
