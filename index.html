v3.6.21.6
Out now/ 01

On KGX Core

The toolbox now runs on KGX Core, the shared library of the KGX addons: one language, NEW tags and net budget for every KGX addon, and their admin actions in the toolbox's Action Log. No change to any tool or panel. Built on v3.6.21.5.1 Alt + E Buttons and v3.6.21.5 Screens.

  • Listed in Q menu > Utilities > KGX > KGX Core, with a note when a newer version is on the Workshop
  • The toolbox's language is KGX Core's: pick it once for every KGX addon (an existing server's language is kept)
  • Throw Equipped and Pickup Equipped settings changes appear in the Action Log and Discord logs
  • v3.6.21.5.1: Alt + E buttons and live income on treasury screens; v3.6.21.5: the treasury and stores on screens

    KGX’s Admin Toolbox

    A Garry’s Mod admin tool set by KGX PRODUCTIONS. This is your place to follow its development, see what’s in progress, and explore the improvements planned for future releases.

    View the addon on Steam

    Getting started

    Open the Steam Workshop page and select Subscribe. Allow Steam to download the addon before launching Garry’s Mod. The Workshop page is also the place to find the published addon’s details and updates.
