Create Storage

Turn props into storage or loot containers (crates, lockers, cabinets).

Tool / Covers v3.6.21.6.1 / Updated Oct 27, 2026

What it does

Create Storage turns a prop into a container, or places a new one on the ground. Players open containers with E. Taking an item puts it in your backpack; money goes to your wallet.

There are two kinds. Storage containers keep what players put in them, also across restarts. Loot containers fill themselves from a loot table and refill after a timer. Only toolbox admins can set up loot containers.

Each container has its own access rule, an optional code and an optional search time. Containers are saved per map and come back after cleanups and restarts.

Where to find it

Q menu > KGX's Admin Toolbox > World > Create Storage.

Toolbox admins can use it. Superadmins can also give it to players in Settings > Player Access. Players then manage only their own containers and can read the loot tables.

Given to a player (v3.6.11.3): Their own containers; read the loot tables.

Contents

A list with Kind, Item and Amount. Admins add items by hand: pick a kind (Weapon, Ammo, Item (entity), Money), enter a class or click Pick..., set the amount, then Add. Remove selected and Remove all clear entries. Players cannot add items here.

How to use it

Turn a prop into a storage crate
  1. Spawn a crate prop and place it.
  2. Set Type to Crate (8 slots).
  3. Aim at the prop and left-click. It keeps its look and spot.
  4. Press E on it: the container is on the left, your backpack on the right.
Make a loot crate that refills
  1. Place a container, then right-click it.
  2. On General, set Kind to Loot: fills itself from a loot table (admins).
  3. On Loot, pick a Loot table such as Basic supplies and set the items per fill.
  4. Set Refill after (minutes, 0 = never) and click Save.
  5. The crate glows while it has loot for you and shows Empty once looted.
Lock a locker to certain players
  1. Right-click the container and open Access.
  2. Set Who can open it to Whitelist: only the players and ranks below.
  3. Add players with Add an online player... or ranks with Add a rank....
  4. Optionally enter a Code, then click Save.
Remove a container
  1. Aim at it and press reload.
  2. Press reload again within 3 seconds. The container and everything in it are removed.

Settings and commands

Change these in Settings > Backpack & Storage (superadmins).

Setting What it does Default Range
kgxat_storage 1 = storage containers can be opened. With it off, the tool cannot make new ones. 1 0 to 1
kgxat_storage_glow 1 = containers with loot for you glow when you are close. 1 0 to 1
kgxat_storage_labels 1 = container names (and Empty) float above them. 1 0 to 1
kgxat_backpack_blacklist Comma-separated weapon or item classes that can never go in a backpack or container. Empty
kgxat_limit_storage Most containers a non-admin player may own (Settings > Limits). 0 = not allowed. 2 0 to 100

Tips and limits

  • Players given this tool convert only props they own (not permanent or server-owned ones).
  • Saved per map in data/kgx_admin_toolbox/storage_<map>.json.
  • You cannot convert players, NPCs, vehicles, weapons, map props or stores. Aim at a prop you spawned.
  • Admins can move containers with the physics gun; the new spot is saved. Players cannot move them.
  • Admins and the owner can always open a container and skip the code. Only admins skip the search time.
  • Five wrong codes lock the container for that player for 15 seconds.
  • Changing Kind, the loot table or Loot is starts fresh loot.
  • Money from loot is skipped while the economy is off.
  • Keys, Admin Keys, Pockets, Hands and money printers can never be stored.
  • Containers cannot be made Permanent Entities; they save themselves.
  • v3.6.15: containers and vaults do not open for players in a Game Modes match, and stores refuse them, so match weapons cannot be stored or sold.
