FAQ

Questions, answered.

The questions server owners ask most. More in Help; something else? Ask or report it.

Does it work with DarkRP?

Yes. It runs in Sandbox and Sandbox-based gamemodes that use the tool gun, DarkRP included. While DarkRP runs, the toolbox's RP mode uses DarkRP's own jobs, doors, keys and rules, and money is DarkRP's wallet. The Mayor commands stay off on DarkRP unless kgxat_mayor_with_darkrp is on (DarkRP has its own). Full DarkRP support, with a setting for each overlap, is the next update on the roadmap.

Does it work with ULX, SAM or sAdmin?

Yes. With an admin mod that supports CAMI (ULX, SAM, sAdmin and others) the privilege KGX Admin Toolbox decides who is a toolbox admin; its default minimum rank is admin. Without one, admin and superadmin can use it. See Getting Started.

Why can my players not use a tool?

Tools are admin-only until a superadmin allows them: Q menu > KGX's Admin Toolbox > Settings > Player Access, for all players or one rank. Settings > Tool Visibility can also hide a tool, and Settings > Licenses can hand tools out with a Tool License.

Where are the settings and data saved?

On the server in garrysmod/data/kgx_admin_toolbox/. Back it up or restore it with Settings > Backup / Restore. A file that cannot be read is moved to _broken/ and the last good copy in _bak/ is used. Favorites and seen NEW tags are kept on each player's own computer.

How do I reset everything?

Settings > Server Settings has Reset everything / wipe map data. It makes a backup first, so a wipe can be undone in Settings > Backup / Restore.

Can players see it in their own language?

Yes: Settings > Display > Language (English, Español, Deutsch, Français, Русский, Português (Brasil)), or the server's default from Settings > Translations. The console command is kgxat_lang. Admin panels are still English; translating them is planned.

How do I install it on a dedicated server?

Subscribe on the Steam Workshop and add it to your server's Workshop collection, or extract the kgx_admin_toolbox folder into garrysmod/addons/. Restart the server; players download it automatically.

Where are the patch notes in the game?

Q menu > KGX's Admin Toolbox > Settings > Patch Notes & README, or the console commands kgxat_patchnotes and kgxat_readme. Every release is also on the Releases page.

I found a bug. Where do I report it?

Use the bug report form on GitHub: your toolbox version (on the Q menu tab), the gamemode, what happened and how to make it happen again. Console errors help the most. A comment on the Workshop page works too.

What is KGX Core and why is it a required item?

KGX Core is the shared library the KGX addons run on: the registry, networking, data files, permissions, translations and the UI kit, installed once. An addon that needs it lists it as a required item, so subscribing to the addon subscribes you to Core too. On its own it adds one page to the Q menu (Utilities > KGX > KGX Core).

Can I edit the files or re-upload the addon?

No. The toolbox is not open source: subscribing lets you run it unchanged on your game or server. Edits are lost on updates and are not supported; everything is set in the game (Q menu > KGX's Admin Toolbox > Settings). Re-uploads are reported for takedown.
