KGX TRADE POST TOOL

Trade Post Item Catalog.Find the name, copy the command.

Every vanilla 7 Days to Die item players can trade at KGX Trade Post, with the internal name the admin commands need. Pick an item, set a price and copy a ready serverbuy or serversell command into the F1 console.

Get KGX Trade Post Trade Post roadmap

Command builder

serverbuy: the server pays players for the item. serversell: the server makes the item and sells it (items without quality only). Count 0 means it never runs out. Run the command as an admin (permission trade.admin).

From the game files of 7 Days to Die V3.4: items players can craft, loot, buy from traders, harvest, or make from another item; developer, test and admin items are left out (the same rule as the Order items list in KGX Trade Post). Base value is the game's value of one item before trader markups. Items added by other mods are not listed: on a modded server, the Order items list in game is the full list. Blocks such as Iron Door appear as the item players craft and carry.
